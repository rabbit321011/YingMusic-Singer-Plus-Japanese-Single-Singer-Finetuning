# V4 版本

V4 引入了 A/B 区分割设计，首次实现自重建可用。经过 V4a、V4b、V4c 多轮迭代，
最终 V4c step 24000 为最佳 checkpoint。同时包含 GRPO 实验。

## 目录

| 目录 | 内容 |
|---|---|
| `计划/` | V4 完整执行计划（v0527、v2） |
| `训练/` | V4 系列训练记录 + 给作者的外部报告 |
| `GRPO/` | GRPO 训练计划 + 调试日志 |
| `调试/` | 文本辅助损失方案探索 |

## 阅读顺序

先读 `计划/` 了解设计意图 → 再读 `训练/` 了解实际过程和结果。
`GRPO/` 和 `调试/` 相对独立，可按需阅读。
