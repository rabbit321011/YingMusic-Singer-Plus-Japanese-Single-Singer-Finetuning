## 一、框架总览：作为谁 × 谁为作

岛岛提出的核心分析框架，将歌声生成拆解为两个正交维度。这个框架的价值在于：把 V4 混乱的失败现象（咬字崩、旋律漂、唱功退化）映射到了一个可操作的概念体系。

### 1.1 作为谁（歌手身份）

**问题**：SVS 模型没有天然的"身份"。人类歌手有"风格"作为上下文——观众听到意外之处会说"这是她的风格"。但 AI 的任何输出偏差都被视为缺陷。V4 的花丸模型处于后者——输出偏差=咬字错误/旋律崩塌，没有"身份"来消化这些偏差。

**核心洞察**：观看者完全不了解原子个体的实际情况，其只能组建出一个片面的原子个体。如果原子个体有其身份，那么其产生的意外之物就会被接受，反之则会被认为是对原子个体的伪劣。SVS 生成式 AI 明显属于后者。

---

**方案 A：SVC 教师蒸馏**

- **思路**：SVS 输出过 SVC，SVC 出来的必然是花丸音色，SVS 以 SVC 输出为目标训练
- **本质**：teacher-student 蒸馏——SVC 是 identity enforcer，SVS 是 student
- **学术对应**：CoMoSVC 一致性蒸馏（1 步推理达教师 40 步质量）、Learn2Sing 教师-学生范式
- **优势**：比单纯的音色 embedding 更强更确定——不需要"猜"花丸怎么唱，直接从 SVC 输出学

---

**方案 B：BYOL 自监督歌手身份**

- Sony CSL Paris (ISMIR 2023/arXiv 2024)：BYOL 在跨域泛化上最优，参数量比 Wav2Vec-base 少 19 倍
- BYOL 不压缩域内方差——不像对比学习那样推开相似歌手，保留更多表达性变化
- 可用于替代 SVC 教师模型中的说话人嵌入，减少对 SVC 教师的依赖

---

**方案 C：子中心嵌入**

- **论文**：Sub-Center Speaker Embeddings (arXiv:2407.04291)
- 用 20 个子中心 (C=20, T=1) 代替单一说话人嵌入，保留类内方差→更自然的表达
- 实验结果：高方差→更好的自然度和可懂度 (WER↓)；低方差→更好的说话人相似度 (SECS↑)
- 跟岛岛的"性格不能创新也不能拟合，只能重现"一致——多个子中心让模型有了"选择的余地"

### 1.2 谁为作（唱歌动作）

五个子维度，每个有对应的 loss 信号或技术方案：

**① 唱功**
- 岛岛：GRPO/YMSP 原文有唱功奖励模型
- 学术：YingMusic-Singer-Plus GRPO 四维奖励（ASR_WER+F0_CORR+QwenFeat+WavLM_Sim，各 0.25 权重）
- V4 实际：GRPO 仅 +4.4% PER，统计不显著。唱功维度可能需要更强的信号

**② Text 咬字**
- **CE 辅助损失**（来自 temp_0701/文本辅助损失方案探索.md）：Whisper teacher-forcing CE loss
- 优势：确定性梯度（vs GRPO 策略梯度高方差）、连续概率信号（vs 离散 reward）
- 风险：Whisper 偏好 (reward hacking)、日语 tokenizer 精度、0.01 小权重可能不够力
- 定位：V5 主线后的低优先级辅助项，约 250ms/step，仅 35% step 触发

**③ Text 对齐**
- 岛岛描述：5 个音符对应 4 个字→字容易错位、开始时间错误、过早结束。V4ca 有这个问题
- **DiTSinger 隐式对齐** (arXiv:2510.09016)：字符级 attention mask + 加性偏置，无需音素级时长标注
- **BBC 编码器** (TCSinger 2, ACL 2025)：音素边界随机掩码，处理边界模糊性
- **CPC 对比预测编码** (Wang et al. 2022, Interspeech)：预测未来声学表征，平滑对齐误差，已在 SVC 验证
- YingMusic 当前问题：text_mask_padding=False，完全无对齐约束，30+字自然崩塌

**④ MIDI 旋律**
- 已有专门 loss (CKA melody alignment loss)
- 岛岛：这部分目前问题不大

**⑤ 性格/live 存在**
- 岛岛核心洞察：性格不能创新，也不能拟合，其只能重现片段。理想方案是完全追随 cond 的性格
- 学术对应：子中心嵌入保留表达变化、层次化说话人表示框架（不同粒度的时间统计量）
- 关键权衡：高类内方差→更好的自然度和可懂度；低方差→更好的说话人相似度

## 二、核心理论：平均化税与条件集

### 2.1 平均化的数学本质

**Averaging Tax 理论**（Abhishek Shankar Blog, 2026）：所有用 MSE loss 训练的扩散/流匹配模型，其最优预测器永远是条件均值 E[v|x_t, t]。在多模态的中间点，这个均值指向"没有真实轨迹使用的方向"——导致生成模糊、模式覆盖差。这不是模型缺陷，是 MSE loss 的数学必然。加参数、加数据、换架构都不改变这个极限。

**对 V4 的直接解释**：
- FlowB=0.90 的地板不是"模型只能学到这个程度"，而是"MSE 在这个条件集下只能到这个程度"
- 模型没有变笨——MSE loss 在忠实地执行它的数学使命：给条件期望
- 问题在于"条件期望"在歌声这种高度多模态的任务里，天然不等于"好的输出"

**唯一解法**：缩小条件集——让模型面对更窄的条件范围，减少需要"平均掉"的歧义。规模不解决问题：更多参数/数据/架构不改变极限——所有扩散/流匹配架构收敛到同样的条件均值。

### 2.2 条件集与加强 cond

条件集 = 模型收到的所有条件信号：text、midi、cond（音色参考）、时间 t。

**缩小条件集的实际含义**——让每个条件信号更确定：
- 更好的 text 对齐 → 每个帧只有 1-2 个可能音素，不需要在 5 个音素里"平均"
- 更精确的 midi → 音高范围更窄
- 更强的 cond → 音色参考更清晰，B 区不再 cond=0 裸奔 20 秒
- SVC 教师 → 身份条件比单纯 embedding 更强更确定

岛岛的直觉"加强 cond 的影响"完全正确——cond 越强，模型越不需要"平均"，越能产出确定性的、有性格的输出。

DiTSinger 的隐式对齐就是缩小条件集的典型案例——通过注意力掩码把每个 mel 帧的条件集从"整个音素序列"缩小到"当前字符的几个音素"。

### 2.3 平均化区间假说

岛岛假说：训练存在三个阶段——
- **0~a**：未拟合，loss 快速下降，模型在学习基础映射
- **a~b**：平均化陷阱，FlowB 不降，A 区随机替换导致的损失也不降或反而升高
- **b~1**：拟合成功，精细调优

岛岛猜想：是否应该放大 0~a 的信号、缩小 a~b 的信号、放大 b~1 的信号？

**学术对应——Low-Noise Pathology** (arXiv:2509.20952)：
- t 很小时（噪声很低），flow matching 的 loss landscape 条件数 κ = ||Δv||/||Δx|| 发散到无穷
- 导致三个效应：病态优化、Jacobian 重分配（编码器把有限容量分配给噪声方向）、表示退化
- 这可能是平均化区间的精确数学表达

**检测方法**（用于实际训练中判断是否进入平均化）：
1. **Jacobian 条件数追踪**：κ = var(v_target)/var(x_t)，κ 突然飙升 → 进入区间
2. **编码器特征方差**：方差突然下降 → 模型在输出平均值
3. **F0 RMSE 变化趋势**：F0 误差增大 → 过度平滑
4. **样本多样性**：帧级 F0 std 下降 → 所有输出趋同

**LCF (Local Contrastive Flow) 解决方案**：
- t ≥ T_min：标准 flow matching（velocity regression）
- t < T_min：对比特征对齐替代 velocity regression（InfoNCE loss）
- 推荐 T_min ≈ 0.01-0.05（连续时间），CIFAR-10 上 T_min=20/1000（离散步）

## 三、Loss 设计原则

### 3.1 Loss 齐头并进原则

**岛岛的直觉**：理想学习应该是各个 loss 组成成分，在没学完的成分中，降低难度始终差不多。

**学术对应——GradNorm** (ICML 2018, arXiv:1711.02257)：原文："The correct balance is struck when tasks are training at similar rates." 核心机制：每步检测各 loss 组件相对于初始值的下降比例，下降慢的自动加权，下降快的自动降权。单超参数 α 控制恢复平衡的力度。

**对 V4 的诊断**：Flow loss (MSE) 降得飞快，咬字相关指标一动不动。模型走了"直接拟合 mel 频谱"的捷径——这就是 shortcut learning (Nature Machine Intelligence 2020 综述)。用 GradNorm 的话说：Flow loss 的训练速率远远快于 text 相关 loss，平衡被打破。

**GradNorm 在 SVS/TTS 领域的现状**：主流 TTS (VITS、ESPnet 等) 目前用的都是固定 loss 权重，没人做动态平衡。VITS 论文自认"对 reconstruction loss 的权重极其敏感"。在 SVS/TTS 领域使用 GradNorm 是领先的。

### 3.2 Loss 的复合性

**岛岛的观察**：部分 loss 不是单一信号，而是多个信号的组合。Flow B 同时包含文本、midi、性格以及更多。调节一个会影响另一个。

**对 GradNorm 的影响**：GradNorm 假设各 loss 是独立的，但 SVS 中 loss 有包含关系——Flow B 里的"文本部分"和 CE loss 里的"文本部分"是重叠的。直接套用 GradNorm 可能导致权重振荡。需要先搞清楚各 loss 之间的"包含关系"——哪些是纯信号 (CE loss 只关心文本)，哪些是混合信号 (Flow B 同时包含文本+midi+性格)。

**UniVoice 的解法** (arXiv:2606.05852)：因子化条件分解——每个条件有独立 encoder 和独立梯度路径。语音模式用 null token 替代旋律条件。论文证明因子化消除了语音和歌声之间的梯度冲突。

### 3.3 Loss 幅度调节

**岛岛原则**：所有 loss 不能由某个评定器直接输入进去，肯定是要变化一下幅度的。

**学术对应**——四个层次：

| 层次 | 方法 | 核心思想 |
|:---:|------|---------|
| ① Loss 尺度平衡 | 对数变换 / 不确定性加权 | 让各 loss 数值可比较 |
| ② 梯度幅度平衡 | GradNorm / 梯度归一化 | 让各 loss 梯度幅度一致 |
| ③ 梯度方向平衡 | PCGrad / GradDrop / CAGrad | 解决梯度冲突 |
| ④ 训练进度平衡 | AMTL / DWA / IGB / CoBa | 每个组件相对于自身难度的优化状态 |

真正的平衡发生在第四层：**训练进度**——每个组件相对于其自身难度的优化状态。

**AMTL** (ICCV 2023)：用加权几何均值替代加权和——因为加权和容易被数值最大的 loss 主导，几何均值对尺度不敏感，能真实反映所有 loss 的进展。

### 3.4 对比 Loss 方案（岛岛原创推导）

**岛岛的方程推导**：设 EE = 模型预测，target = BE，loss = LE。则 EE = BE - LE。又 EE = Eavg + EcondE（Eavg = 平均成分，EcondE = cond 特定成分）。替换 A 区音频为 AN 后：EN = BE - LN，EN = Eavg + EcondN。目标是提取并强化 EcondE，但直接解不出方程。

**间接方案**：

```
Loss = n·LE + LE - 1/3·(LN + LF + LG) ，n < 1
等价于：(1+n)·LE - mean(L_alternatives)
```

直觉：放大正确 cond 的 loss 权重，减去错误 cond 的平均 loss。模型被激励去利用 cond 中的特定信息——因为只用"平均信息"的话，LE 和 LN 差不多，loss 就不会降低。

**学术对应——ΔFM** (ICCV 2025, arXiv:2506.05350)：

```
L_ΔFM = ||v̂ - v⁺||² - λ·||v̂ - v⁻||²
```

跟岛岛的 `(1+n)·LE - mean(L_alternatives)` 本质完全一样——都是"正损失 - 负损失"的对比结构。

**ΔFM 实现细节**：
- 代码改动极小：只改 loss 函数，不动模型架构，不增加前向传播
- 负样本从 batch 内随机采样（只需 randperm 一次），不需要岛岛的"A 区替换+慢更新"工程优化
- λ=0.05 在图像任务上最优且跨设定稳定。音频 TTS (RobustSpeechFlow) 用了 λ=0.2
- 训练加速 9 倍（达到同等 FID 只需 1/9 步数），推理加速 5 倍（仅需 1/5 去噪步数）
- 与 CFG 兼容：使用修正公式 `CFG = (1-λ)[w·v(y)+(1-w)·v(∅)] + λ·T̂`
- GitHub: https://github.com/gstoica27/DeltaFM, MIT License

**ΔFM 在 SVS 中是明确的研究空白**：目前没有任何 SVS 工作用过 ΔFM。最接近的是 RobustSpeechFlow (TTS)，用了 Repeat/Skip 增强作为硬负样本。岛岛如果做了就是**首个**在 SVS 上用对比流匹配的。

**岛岛的"每 10-50 步更新替代 loss"工程优化**：ΔFM 证明了每步随机采样就够，不需要慢更新。但如果岛岛想更精细地构造负样本（替换 A 区音频而非随机采样），效果可能更好——代价是更高计算量。建议先试简单的 ΔFM，再考虑 A 区替换版本。

## 四、技术方案详情

### 4.1 数据集方案（材料4更新）

**最终确定**：Emilia 日语 + JSUT + JVS + 花丸

| 数据集 | 规模 | 质量 | 标注 | 获取 | 用途 |
|--------|:----:|:----:|:----:|:----:|:----:|
| Emilia 日语 | 2,800h | 24kHz 需重采样 | ASR 转录中等 | HuggingFace gated 已申请 | 发音基础主力 |
| JSUT | 10h | 48kHz 最高 | 朗读脚本近乎完美 | GitHub 免费 | 质量锚点+验证 |
| JVS | 30h | 24kHz 需重采样 | 100 位专业声优脚本 | 官网免费 | 多风格补充 |
| 花丸晴琉 | 90h | MSST 分离后 | Whisper 时间戳 P95=6.62s | 已有 | 唱歌+音色 |

**排除的数据集**：
- Galgame 10,588h：HTTP 451 版权封锁，动画声线偏差，性别严重失衡
- J-CHAT 69,000h：无现成音频，仅 YouTube URL 列表+ASR 转录，需 yt-dlp 爬取数周

**数据量论证**：
- Jmica JA_21999120 从零训练日语 F5-TTS 用了 7,100h
- 但 V5 是从 YingMusic CN/EN DiT 权重出发的**增量训练**，不是从零开始
- F5-TTS 社区验证：微调新语言只需 10-15h 即可
- SVS 发音预训练门槛更低：DiffSinger 从零训练单歌手只需 ~5h，NNSVS 日语 SVS 用 4.35h
- 日语仅有约 50 个假名音节，音素覆盖率比中英文都容易达成
- **结论：2,840h 朗读数据对 V5 目标绰绰有余**

**数据质量铁律**（F5-TTS 社区验证）：
- 20 分钟干净录音 > 2 小时嘈杂录音
- JSUT 10h 48kHz 的质量锚点价值远超其时长
- JVS 100 位专业声优的发音质量顶级

### 4.2 V5 训练主线（材料4确认）

- **混合训练**：70% 朗读 TTS + 30% 唱歌 SVS，同 batch 混合，WeightedRandomSampler
- **SPFM 数据自净化**：t=0.5 比较 L_cond vs L_uncond，自动过滤脏数据，40k 步 warmup
- **Wet 仿真增强**：随机加混响/回声/和声 + F0 扰动，消除干湿 gap
- **UniVoice null melody token**：TTS 模式用可学习 token 代替 midi=0（可选优化）
- **超参**：LR 1e-5 起步，frame 模式 batch，fp16 精度，500k-700k 步，每 5 epoch 人耳评估

### 4.3 VAE 方案

**短期**（立即启动）：
- 冻结 SAO VAE encoder+bottleneck，只微调 decoder
- stable-audio-tools 自带 `decoder_finetune=True` 参数（未暴露在 factory.py，需自定义 Python 脚本）
- 50k-100k 步，1-2×RTX 4090，LR 1.5e-4
- 社区验证：lyraaaa/sao_vae_tuned_100k (HuggingFace)
- latent space 完全不变 → DiT 不需重训

**中期**（等开源）：
- **STAR-VAE** (ICML 2026, arXiv:2606.23064)
- 同帧率 21.5Hz、同 latent dim（可能 64），语义保留改善 30-64%
- 预计 2026 年 7 月 9 日 ICML poster 后可能发布代码和权重
- 如果 latent dim=64，可 drop-in 替换

**备选**：
- **Semantic-DACVAE-Japanese** (Aratako, HuggingFace)：日语专用，UTMOSv2 超原版，但 latent 维度不同需改 DiT 输入层
- **εar-VAE**：43Hz 帧率两倍，语义保留不如 STAR-VAE

**SAO VAE 日语局限**：训练数据 AudioSparx 几乎不含日语；21.5Hz 帧率 46.5ms/帧，日语短辅音 VOT 20-50ms 在临界点；论文自认 "speech generations are not intelligible"。

### 4.4 对比学习增强（V5 辅助 loss）

| 方案 | 核心公式 | 作用 | 实现复杂度 |
|------|---------|:----:|:--------:|
| **ΔFM 对比正则化** | FM loss - 0.05×MSE(v_pred, v_neg) | 对抗平均化 | 极低（几行代码） |
| **CPC 对比预测编码** | 预测未来 k 步声学表征，最大化互信息 | 丢弃局部错误，增强时序平滑 | 中等 |
| **CoMelSinger** | 序列级（同一语义不同音高）+帧级（同一音高不同文本） | 双粒度对比 | 较高 |

- ΔFM 负样本从 batch 随机采样，代码改动极小，不增加前向传播
- 与 SPFM/Wet 增强/混合训练正交叠加
- CPC 已在 SVC 验证 (Wang et al. 2022 Interspeech)

### 4.5 对齐增强

| 方案 | 方法 | 是否需要时长标注 | 来源 |
|------|------|:--------------:|:----:|
| **DiTSinger 隐式对齐** | 字符级 attention mask + 加性偏置 M∈R^(L_mel×L_ph) | 否 | arXiv:2510.09016 |
| **BBC 编码器** | 音素边界处随机掩码 m 个 token | 否 | TCSinger 2, ACL 2025 |
| **CPC 时序平滑** | 预测未来声学表征，平滑对齐误差 | 否 | Wang et al. 2022 |

- DiTSinger：窗口内 M=0（允许注意），窗口外 M=-∞（禁止注意）
- BBC 编码器：数据增强策略，不修改对齐机制本身

### 4.6 训练阶段检测

| 方法 | 核心思想 | 来源 |
|------|---------|:----:|
| **Low-Noise Pathology** | t 很小时 loss landscape 条件数发散到无穷 | arXiv:2509.20952 |
| **LCF 局部对比流** | t<T_min 时切换到 contrastive loss 替代 MSE | arXiv:2509.20952 |

- 检测方法：Jacobian 条件数追踪、编码器特征方差、F0 RMSE 趋势
- 推荐 T_min ≈ 0.01-0.05

### 4.7 后处理增强

| 方案 | 作用 | 来源 |
|------|:----:|:----:|
| **GAN 多频带判别器** | 对抗平均化效应，特别改善中高频细节 | XiaoiceSing2 / WeSinger2 |
| **多教师蒸馏** | SVC(音色)+ASR(内容)+Pitch(旋律)+HiFi-GAN(质量) | — |

- 音频预处理：全部重采样至 44.1kHz → VAE encode → latent

**VAE 解码器微调（可并行）**：
- 下载 SAO VAE checkpoint (stable-audio-open-1.0, vae_model.ckpt)
- 自定义 Python 脚本调用 AutoencoderTrainingWrapper (decoder_finetune=True)
- 日语数据微调 50k-100k 步，LR 1.5e-4，1-2×RTX 4090
- 冻结 encoder+bottleneck → latent 不变 → DiT 不需重训

### 5.2 Phase 2：V5 训练（2-4 周）

**主线**：
- [ ] 改造 V4 训练脚本：数据加载器 WeightedRandomSampler 70/30
- [ ] 朗读：midi=0, 无 CKA
- [ ] 唱歌：midi 开, CKA 开
- [ ] SPFM：t=0.5 比较 L_cond vs L_uncond，40k 步 warmup
- [ ] Wet 增强：数据预处理加混响/回声/和声 + F0 扰动
- [ ] 超参：LR 1e-5, frame batch, fp16, 500k-700k 步
- [ ] 监控：PER、F0-CORR、Flow Loss，每 5 epoch 人耳评估

**辅助 loss（可并行加入）**：
- [ ] ΔFM 对比正则化：标准 FM loss - 0.05×MSE(v_pred, v_neg)
- [ ] GradNorm 动态 loss 平衡（如果主线 loss 不平衡很明显）
- [ ] CE 辅助损失（主线稳定后，作为低权重辅助项）

### 5.3 Phase 3：进阶优化（V5 稳定后）

- [ ] SVC 教师蒸馏：训 SVC 教师 → 一致性蒸馏至 SVS 学生

- [ ] CPC 时序平滑：预测未来声学表征，作为额外正则化
