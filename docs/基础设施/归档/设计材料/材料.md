## 一、项目与问题

### 1.1 项目背景

**项目**：YingMusic-Singer-Plus（453M F5-TTS DiT 22层）日语 SFT 微调
**目标**：在官方 CN/EN 权重基础上，实现花丸晴琉音色的日文改词翻唱
**数据**：15,122 条花丸晴琉日语翻唱干声（~90.7h），Whisper large-v3 自动标注
**硬件**：4× RTX 4090 (24GB) DDP 训练

### 1.2 训练历程

| 版本 | 设计 | 问题 | 结果 |
|------|------|------|:---:|
| V1 | cond = full_latent = GT | 作弊：模型直接从 cond 抄答案 | 自重建完美，改词翻唱完全失败 |
| V2 | G2P 日文路由错误 | `encode_ja()` 替换为 `tokenizer.encode()` 后日文被 `get_segment()` 判为 "other" | 第 50 步崩溃 |
| V3 | 修复 cond，但 x_t 每帧泄漏真实值 | 训练正常，推理全噪声（训练/推理分布不一致） | 推理失败 |
| V4 | A/B 区分割：A区 cond=GT/midi=0，B区 cond=0/midi=GT | FlowB 硬地板 0.90（V1=0.45），30+字长文本崩塌 | PER=0.387 |
| V4b | L1+L2+L3 数据，19k 步 | — | 糊但能听歌词 |
| V4c | L1+L2 数据，30k 步 | — | 22k 歌词最佳，电音感 |
| V4ca | L1 only，6k 步 | — | 与 V4c 差不多 |
| GRPO v2→v3 | G=8, 4-reward, 4800步 | PER 仅 +4.4%（800步峰值），1200步后回落 | 非显著改善 |
| V5a1 | 课程训练（midi全零/CKA关/text dropout关），24K步 | 双测试集+人耳A/B均无咬字提升 | 回退V4c 24K |

### 1.3 关键现象

岛岛描述的关键现象：

- **咬字**：第1-2句是准的，第3句开始就崩了
- **旋律**：第1句会崩，但是2-3句就准了
- **30+字**长文本：PER 断崖式崩塌至 0.141（120首分层评估中该bucket稳定性96.7%但PER最低）
- SFT 24K 总体 PER=0.387（官方 YingMusic 约 0.08）
- **SVC 微调也有类似现象**："微调越多，质量越差"。但 SVC 可以通过小规模、小 LR 的微调避免。而 SVS 必须微调出日语能力，"等调出日语能力，唱功、旋律就崩了"
- 和官方的比"差远了"，包括咬字自然度和唱功

### 1.4 分层评估数据

| Bucket | avg_PER | 稳定性 | 分析 |

## 二、根因分析

### 2.1 A/B 分割的 B 区误差累积（嫌疑最大）

A/B 分割设计：
- A区（参考区，前 ref_len=12.5%-33% T 的帧）：cond=真 latent，midi=0
- B区（生成区，剩余帧）：cond=0，midi=真旋律

**问题**：B 区 cond=0 始终成立，模型在训练时被教成"B 区不需要太在意 text，主要靠 midi"。对于典型样本（中位数 23.2 秒，中位数 5 句），ref_len 可能只覆盖第 1 句（2-3 秒），之后长达 20 秒全是 B 区。text 信号（28 个从零开始的日语 embedding）撑不了这么远，模型越来越依赖 midi，咬字逐帧漂移。

这完美解释了岛岛的观察：
- 咬字 1-2 句准 → A 区及刚进入 B 区时 text 信号尚可
- 咬字 3 句崩 → B 区深入后 text 信号衰减
- 旋律 1 句崩 → A 区 midi=0，旋律无引导
- 旋律 2-3 句准 → B 区 midi=GT，旋律稳定

### 2.2 日语 Text Embedding 弱

CNENTokenizer（IPA tokenizer）共 366 个 token（PAD=0, 音素 1-363, PUNCT=364, SEP=365）。日语仅占 28 个槽位（ID 319-346），且 27/28 在 V4 之前从未训练。通过 optimizer state 交叉验证确认：日语区域 AdamW 动量值接近零，确认为未训练。

**三层独立性**（来自 VOCAB_TOKEN_MAP.md）：

| 层 | 状态 |
|---|---|
| G2P (文本→音素) | ✅ 已改（加日文支持，pyopenjtalk） |
| Tokenizer (音素→ID) | ❌ 未改（官方原版，28 个 JA 槽位） |
| Embedding (ID→向量) | ❌ 未改（官方原版，27/28 未训练） |

### 2.3 数据质量问题

**效果器残留**：花丸翻唱经常挂混响和 delay，MSST 人声分离后效果不一定去干净。模型可能把混响尾音也当成"花丸的声音特征"来学。

**伴奏分离不净**：MSST（duality_v2→fused→denoise 三步骤）可能残留和声、伴奏漏音。

**时间戳不准**：Whisper large-v3 + difflib 模糊匹配方案（A7），P95 误差 = 6.62 秒。

数据分档：

| 分档 | 条件 | 条数 | 占比 |
|------|------|-----:|:---:|
| L1_high | sim≥0.9 且 句数≤10 | 7,725 | 51% |
| L2_medium | sim≥0.7 | 3,924 | 26% |
| L3_low | sim≥0.5 | 967 | 6.4% |
| L4_discard | sim<0.5 | 2,243 | 15% |

L1 高质量数据只占 51%，意味着近一半训练数据存在不同程度的时间戳偏差。

### 2.4 "动情特征"与 SFT 趋向均值

岛岛提出的理论（尚未完全成型）：

> "动情特征不是平均的，而是抽查的，而 SFT 非常容易训出平均值"
> "如果是她，她会怎么做"

MSE loss 本质是条件期望：给定 text+midi+cond，输出"最平均"的 latent。但歌手的表达不是平均的——同一个音在不同情绪、不同段落下处理方式完全不同。SFT 把这些全平均掉了，出来的是"哪种都不像"的中庸发音。训练越久，方差越小，表达越平。

相关文档片段（岛岛的哲学手稿）：

> 声音模型通过对原子个体的仿效（原子个体其价值在于其动情特征）来生成其艺术价值，而非对动情特征原的拟合来生成

## 四、强化学习方法对比：DiffRO vs GRPO

### 4.1 DiffRO（Differentiable Reward Optimization）

**论文**：Gao et al., "Differentiable Reward Optimization for LLM based TTS system", Interspeech 2025, arXiv:2507.05911

**核心思想**：将奖励计算从音频空间搬到 token 空间，使整个流程可微分。

**三个核心技术**：
1. Gumbel-Softmax 重参数化：替代 argmax 对预测 token 采样，使采样可微分
2. Token2Text 奖励模型：训练一个在 codec token 上运行的 ASR 模型，直接从 token 预测文本后验概率
3. 多任务奖励模型（MTR）：ASR + SER（情感）+ SQA（质量）+ 年龄性别预测

**vs 传统 RLHF**：传统需要 合成音频→vocoder→ASR→奖励（不可微），DiffRO 全程可微，反向传播直接优化。

### 4.2 GRPO（Group Relative Policy Optimization）

**来源**：DeepSeek-Math (Guo et al., 2025)

**核心**：从同一 prompt 采样一组输出（G=8），用组内平均奖励作为 baseline 替代 value network，无需 critic。

**vs PPO**：显存节省 30-50%，训练速度提升约 2 倍。

### 4.3 在 SVS 中的对比

**关键发现**：YingMusic-Singer 本身就是用 Flow-GRPO 的（论文 arXiv:2512.04779）。它的 Flow-GRPO 做法是 ODE→SDE 注入噪声，双奖励：内容准确性（1-WER）+ 旋律相似性（Pearson F0 相关）。

**DiffRO 在 SVS 中完全没有应用**。CosyVoice 3 论文明确写了 DiffRO "不擅长歌声生成"，列为未来方向。

**DiffRO 搬不到 SVS 的坎**：
1. DiffRO 靠 token 空间跑可微分奖励，但歌声的旋律、音高是连续变化的
2. 旋律准确性（F0 Pearson 相关）不可微——当前没有可微分的旋律评估器
3. 好消息：已有 DiffRO + GRPO 组合方案（arXiv:2509.18569），用 Sample Filter 策略结合两者

**结论**：岛岛用 GRPO 不是在走弯路，而是唯一在 SVS 上经过验证的 RL 方法。

### 5.3 跨语言 SVS 技术方案

**CrossSinger**（arXiv 2309.12672）：
- IPA 统一音素空间
- CLN（条件层归一化）注入语言信息
- GRL（梯度反转层）消除歌手-语言绑定

**Transinger**：
- IPA 音素分解为字母+变音符号
- 例如 /tʃʰ/ = t + ʃ + ʰ
- 支持零样本泛化到未见语言

**Muskits**（ESPnet, Interspeech 2022）：
- 多语言预训练 + 目标语言微调策略
- 关键发现：多语言预训练 + 微调 MOS 显著优于单语言训练（3.49 vs 2.90）

### 5.4 日语汉字/假名混合处理

| 问题 | 方法 | 工具 |
