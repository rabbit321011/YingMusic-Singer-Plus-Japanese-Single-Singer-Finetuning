# 材料6：基于Fable 5审查的V5修订计划

> 2026年7月4日，基于Anthropic Claude Fable 5外部审查
> 本文档是对材料4/材料5的优先级重排，不替代原文档

---

## 零、Fable 5核心诊断（一句话）

三个症状（FlowB卡0.90、B区字位漂移、唱功退化）是同一根因的三种表现：**文本条件信号的时间标签噪声过大（P95=6.62s ≈ 142帧 @ 21.53Hz），导致MSE在过宽的条件集上取均值**。材料5的"平均化税"理论和"收窄条件集"方向完全正确，但执行清单没有对齐理论——最直接最便宜的收窄手段（对齐重做）被埋在了昂贵的方案下面。

---

## 一、证据链摘要

| 证据 | 说明 |
|:-----|:-----|
| P95=6.62s，目标±0.5s | 差一个数量级。142帧比一句歌（43-108帧）还长，text token可被整句放进错误区域 |
| L1假消息率13% | 约每7条高质量样本有1条在教错误对应关系 |
| 30+假名桶PER=0.141最好 | text密集时每帧都有token覆盖，时间戳误差影响最小——是"条件集窄→税低"，不是"模型放弃text" |
| 21-30桶PER=0.562最差 | text稀疏时严重依赖时间戳准确性 |
| FlowA 0.41→0.30 | 模型有学习能力 |
| 所有超参改动对FlowB合计±0.02 | 不是优化/超参问题，是标签噪声天花板 |
| V5a1无改善 | 再多训练也无法从噪声标签学出干净映射 |
| GRPO仅+4.4% PER | reward方差被"对齐彩票"主导，advantage信号≈噪声 |

## 二、重排后的优先级总览

```
P0: bake-off四候选对齐（A7分块，句级验收P95<0.5s，B4兜底可接受）
 └─ P0.5: V4d证伪实验（V4c同配方+重对齐数据，fp32，10-20k步，1-2天）
     └─ P1: 日语TTS接地（全数据44.1kHz立体声）
         └─ P2: 重跑SFT（句级放置+时间抖动+SPFM）
             └─ P3: 唱功/身份评估；VAE decoder微调可与P0并行
```

原V5方案中暂缓/降级的项目：

- GRPO：挂起，等SFT PER < 0.1
- ΔFM / GradNorm / CPC：保留为P2之后"压最后0.05"的工具
- 重新扩大数据采集：99h单歌手 + 2800h Emilia-JA已经充分
- 词级放置A/B（P0.5通过后利用B1音素级TextGrid做廉价实验）

## 三、P0：重做对齐（最高优先级）

### 目标

- P95对齐误差：6.62s → < 0.5s（至少一个数量级改善）
- text放置：句级（与官方论文同构，Gold Set句级金标继续有效）

### 分块是最大单一杠杆

A3实验已证明：WhisperX无边界时P95=10.02s，有A7粗边界时降到1.27s——差8倍。A2用MFA做全局对齐得到P95=9.37s，也是因为整条音频对齐导致误差逐句累积。正确做法：A7先粗分句→在每句±窗口内局部强制对齐。分块后误差不再累积，任何对齐器表现都会质变。分块窗口宽度须按A7误差分布设定（如±P90），避免尾部样本真实边界落在窗口外导致对齐器在窗内找假边界。强制对齐的置信分数（MFA有per-utterance log-likelihood）低于阈值的样本标记为可疑而非采信——这批样本正是L1假消息的主要来源，P0验收时应重点检查。

### 方案改为bake-off四候选

- B1: MFA + 花丸99h自训声学模型 + A7分块（最可能赢，域匹配+论文支持）
- B2: MFA + japanese_mfa语音模型 + A7分块（检验A2失败多少来自不分块）
- B3: SOFA Test2_Plus + A7分块（检验社区模型成色）
- B4: WhisperX + A7分块（=A3，已知P95=1.27s，保底baseline）

决策规则：100条Gold Set上P95最小者胜。B1/B3打平选MFA（生态更稳）。若全部不过0.5s，退用B4的1.27s——5倍改善且误差局部有界。

### 粒度-精度决策表

bake-off实测P95与允许的放置粒度：

- P95<0.15s → 摩拉级（后门选项，非主路线）
- P95 0.15-0.5s → 词级（后门选项）
- P95>0.5s（含B4保底1.27s）→ 仍用句级，只收边界收益

主路线为句级，词级/摩拉级为P0.5通过后的后门A/B项。

### 花丸自训MFA声学模型

MFA支持mfa train用自己语料训练声学模型。花丸99h单歌手干声+假名歌词是理想条件——歌手音色一致，MFA的EM算法不需要已有时间戳。OpenVPI DiffSinger管线也是这么做。训出来的模型和音素级TextGrid同时是DiffSinger备选路线数据。

### 验收标准

- 100首Gold Set重新分层
- L1占比大幅上升
- P95<0.5s即通过，B4的1.27s可接受。句级Gold Set金标继续有效无需重标。
- ref_len吸附用新边界

### 推理侧对齐器

推理时翻唱源是任意歌手，B1花丸专用声学模型不能直接使用。推理侧采用人工对齐句边界（±0.1s精度），或通用WhisperX/MFA。训练时对text放置加入时间抖动增强，抖动幅度=训练侧实测P95（如bake-off得0.4s即抖±0.4s），使模型对推理侧放置误差鲁棒。改词翻唱场景的时间戳从源歌词映射，同样靠抖动增强兜底。

## 四、P0.5：V4d证伪实验（1-2天，流程保险）

P0 bake-off完成后，立即用V4c完全相同的配方（同超参、同起点、fp32、什么都不改）在重对齐数据上跑10-20k步。目的：在投入P1/P2大量算力之前，先检验"对齐是根因"这个假设。

三个可证伪预测：

- FlowB明显跌破0.90（此前所有超参改动合计±0.02，跌破即强信号）
- 21-30假名桶PER从0.562显著下降
- B区第一句字位漂移人耳可感缓解

三个信号都动→放心投入P1/P2。都不动→立刻回头重新诊断（VAE/架构/DiffSinger备选路线），省下数周算力。这一步只花1-2天，是整个计划性价比最高的检查点。

## 五、P1：日语TTS接地阶段

### 为什么需要

官方YingMusic的训练课程：1M步TTS预训练 → SFT。V4的28个日语embedding只见了99h带噪对齐的歌声，等于跳过了整个发音先验阶段。先把embedding和ConvNeXt文本编码器在干净数据上喂饱，再回到歌声。

### 数据

- Emilia-JA（语音部分的ASR时间戳天然准确）
- JSUT（10h，48kHz，朗读脚本近乎完美）
- JVS语音部分（100位专业声优）

注意事项：所有数据统一上采样至44.1kHz立体声。Emilia 24kHz→44.1kHz上采样后12kHz以上仍为空（"低通指纹"），不影响P1目标（embedding接地看音素-latent对应不靠高频），但需：JSUT(48k原生)和花丸数据混入一定比例作全频带锚点；单声道数据复制为双声道喂VAE；P2回到全频带歌声会自然矫正。不建议为此上带宽扩展模型。

### 训练要点

- 目标：28个日语embedding + ConvNeXt文本编码器
- midi条件：采用UniVoice式可学习null token。关键：TTS模式、SVS的A区midi=零、CFG drop_midi三处必须统一使用同一个null token——否则模型会学出三种"零"的不同含义，A区midi信号变成一个隐藏变量。
- 防遗忘：混入少量CN/EN或歌唱数据（参考F5-TTS社区经验 #636/#57）

验收指标：

- 合成日语朗读样本Whisper CER<10%（TTS预训练阶段官方PER=0.41的起点，接地后应远好于此）
- 抽测CN/EN样本确认无灾难遗忘（#636/#57的教训要有量化检查，不能只写"混入少量"）

## 六、P2：重对齐数据上重跑SFT

### V4 A/B设计

保持不变。V1/V3的失败反向验证了训练/推理B区一致性原则的正确性。

### 核心配置

- 混合训练：70%朗读（Emilia+JSUT+JVS语音） + 30%唱歌（JVS歌唱+花丸）。若按步数评估发现唱功指标停滞而CER已达标，比例向唱歌侧退火（如70/30→30/70）。
- text放置：句级放置+时间抖动增强（幅度=训练侧实测P95）
- SPFM：t=0.5比较L_cond vs L_uncond，自动跳过残余错标样本（与P0互补非替代）
- Wet增强：可选，消除干湿gap
- LR 1e-5起步，frame batch，默认fp32（V4已验证，P0.5也须fp32保证归因清晰）。若需切换精度以加速训练，先做短程fp32 vs bf16/fp16对照实验再决定。
- 按步数评估（如每20k步），2900h数据下一个epoch过长

### 注意事项

- 确认训练和推理的text放置方式严格同构
- "第三句起胡言乱语"：重对齐后若仍残留，是独立问题（距A区锚点太远→注意力涣散），DiTSinger字符级attention窗口掩码是针对性解法
- L2/L3重对齐后重新分层，L3"均匀分布兜底"类样本大概率直接丢弃
- MFA自训发音词典：kana→音素映射必须用pyopenjtalk统一生成，确保P0产出的TextGrid音素和vocab对得上，否则无法直接喂P2训练
- 长音处理：唱歌超长元音是MFA时长模型软肋。词典里为元音加长音变体（如a→aa），或分块窗口内放宽时长先验。bake-off时留意21-30桶这类慢歌样本的表现

## 七、P3：修复唱功/身份（对齐修好后评估）

如果对齐修好后唱功仍然平庸，区分两个来源：

### 微观韵律被平均掉

- 颤音、滑音、时值微调不在SOME音符级midi里，模型必须自己生成——这是多模态均值最先抹平的东西
- 单歌手99h过拟合理论上应把它烤进权重——前提是标签噪声不再逼模型保守输出
- 对齐修好后再评估，可能自然恢复

### "浴室感"

- 一部分可能是SAO VAE解码器问题（训练数据几乎不含日语，论文自认"speech not intelligible"）
- 冻结encoder微调decoder是低风险并行项，可与P0同时做
- STAR-VAE开源后替换；Semantic-DACVAE-Japanese作为备选

### 技术储备（P2完成后选择性启用）

- 子中心嵌入（20个子中心保留类内方差→更自然表达）
- SVC教师蒸馏（SVS→SVC→以SVC输出为target）

## 八、Fable审查过程中的关键纠正

在Fable 5审查后的讨论中，以下判断被纠正：

1. **"MFA 3.0在CSJ上15ms边界错误"不能迁移到歌声场景**——A2实验用japanese_mfa在花丸歌声上实测P95=9.37s，比Whisper A7的6.62s还差。语音域的精度不等于歌声域。

2. **SOFA并非必然首选**——格罗宁根硕士论文对比显示MFA在歌声上更稳定，但前提是MFA在歌唱数据上训练/适配过。工具选择应通过bake-off实测决策。

3. **分块（A7粗边界引导）是比工具选择更大的变量**——A3验证了8倍改善。

4. **推理侧与训练侧的对齐精度不对称是固有gap**——人工对齐推理侧精度（±0.1s）远高于训练侧自动对齐。但这不构成问题：时间抖动增强将训练侧误差从隐性偏差变为显式建模噪声，两侧不对称自然消解。

## 十、Fable 5列出的核查清单

1. **推理侧text放置方式**：训练和推理是否严格同构？重对齐后重新验证cover场景
2. **"第三句起胡言乱语"**：重对齐后是否残留？残留→注意力涣散问题
3. **L2/L3保留价值**：重对齐后重新分层，L3类样本大概率直接丢弃
4. **A/B设计**：保持不变（已由V1/V3失败反向验证）
5. **GRPO时机**：SFT PER < 0.1再回来，届时v3独立reward server架构直接复用
6. **P0.5证伪通过判据（分级）**：主判据——FlowB跌破0.88（超出此前所有超参改动±0.02噪声带3倍）即通过；辅助判据——21-30桶PER下降、人耳漂移缓解，增强信心但不作为一票否决。若FlowB不动但PER/人耳有改善，延长到20k步再判，仍不动才回头重诊。
7. **精度切换**：P1/P2若需从fp32切换到fp16/bf16，必须先做短程对照实验
