# V4vf 分支

本分支验证 YingMusic-Singer-Plus 的 DiT 在不加载官方 base model 的条件下，
能否仅依靠现有target singer与 V4f 配方从随机初始化学出有效歌声。

## 边界

- `v` 仅表示 DiT 使用源码默认随机初始化，不表示把参数全部置零。
- 保留冻结的官方 VAE、SOME MIDI teacher、tokenizer 与其他数据预处理组件。
- 使用 V4f 的 SOFA token、A/B 训练结构、连续 fuzz MIDI 和官方 VAE。
- 不在本分支引入 MIDI 音符化 `P`，避免同时改变初始化与旋律表示。
- V4vf 只负责随机初始化可行性门禁，不继承到 `V4Pvf`；若门禁通过，`V4Pvf` 将以 `v + P` 从 step 0 联合训练。

## 与其他分支的关系

```text
V4f 配方与数据
  └─ V4vf：随机初始化可行性门禁
       ├─ 可行：允许启动独立的 V4Pvf
       └─ 不可行：主线使用 Official base + P 的 V4Pf

V4Pvf / V4Pf → V5 → V5-MoE
```

`V4Pf` 是平行对照分支，不属于本目录。

## 当前状态

- 显式 random-init 训练入口、初始化审计和多卡梯度同步已实现并验收。
- 低 LR 6k/12k、`LR=1e-4` 30k 和 V4vfg 285k-VAE 适配 10k 均已完成，资源已释放。
- 随机初始化路线在训练指标上可学习；30k FlowB 已接近部分 VAE 适配实验的平台。
- 用户实际试听确认 V4vf 与 V4vfg 均存在大量噪音，未学到可用歌声分布。
- **最终结论：感知门禁失败，停止随机初始化路线；后续回到 Official base 起点的 V4Pf。**
