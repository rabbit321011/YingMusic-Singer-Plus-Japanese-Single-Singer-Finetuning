# 随机初始化可行性实验

## 问题

验证约 329M 参数的 DiT 在不加载 YingMusic-Singer-Plus 官方生成模型权重时，
能否从现有target singer训练数据中学出可辨认日语、有效旋律控制和结构正常的歌声。

本实验是可行性门禁，不以首轮直接超过 V4f 或 V4fg 为要求。

## 唯一主变量

```text
V4f：  DiT = Official base
V4vf： DiT = 源码默认随机初始化
```

保持不变：

- SOFA token 数据与训练/评测清单；
- A/B 区构造、句级文本放置和 loss 定义；
- 连续 SOME melody latent + MIDIFuzzDisturb；
- 官方 VAE；
- batch、随机种子、最大时长和首轮 checkpoint 节点；
- 冻结的 SOME teacher、VAE 与数据预处理组件。

随机初始化必须通过显式参数启用。禁止依靠 checkpoint 路径不存在而静默回退，启动日志必须打印初始化模式，并保存初始权重摘要以便复现。

## 执行阶段

### 参数审计

- 确认未加载 Official、V4f、V4fg 或其他 DiT/Singer checkpoint；
- 确认 VAE 和 SOME teacher 正常加载且冻结；
- 统计可训练参数量、初始化权重范数和关键模块摘要；
- 确认 DDP world size、有效 batch 和各 rank 数据采样正确。

### Smoke test

- 运行 10 步，检查 forward、backward、EMA、保存和恢复；
- 检查 loss 为有限值且参数确实更新；
- 检查日志实时输出 step、各 loss、LR、运行时长和 ETA。

### 同配方门禁

首先复用 V4f 优化配方，保留 `6k / 12k / 24k / 30k` 观察节点。
这一阶段回答“随机模型能否在现有微调预算内学习”，不自动回答从零训练的最终上限。

如果 loss 和生成质量持续改善但明显欠拟合，可另开从零训练专用 LR/步数阶段。
专用阶段必须作为新增变量单独记录，不能与同配方结果混写。

## 可行判据

V4vf 允许进入 V4Pvf 的最低证据：

- FlowB 随训练持续下降，不是无趋势振荡或数值崩溃；
- 固定样本能生成结构正常的声学输出，而非噪声、静音或单调信号；
- F0-CORR 随训练改善，证明连续 MIDI 路径被利用；
- 日语文本从不可辨认发展为可辨认，PER 有稳定下降趋势；
- 延长训练仍有收益，未出现明确不可学习平台。

通过表示随机初始化路线具备继续投入 `v + P` 联合训练的工程价值，
不表示 V4vf 已达到产品可用或超过 Official-base 路线。

## 停止条件

- 数值不稳定且经数据、精度、DDP 和实现审计后仍无法修复；
- 在合理的从零训练学习率和预算下，FlowB、F0-CORR、PER 与听感均无学习趋势；
- 输出长期保持静音、噪声或无旋律结构，且参数更新与数据输入已验证正常。

仅凭 V4f 的微调 LR 下 30k 未收敛，不能单独判定随机初始化不可行。

## Scratch LR 消融

按用户指定先运行 `LR=1e-4`：相同 seed、SOFA 数据、连续 MIDI、官方 VAE、batch、500-step warmup 和 12k 目标，从 step 0 独立训练。输出写入 `ckpts/plus_ja_sft_v4vf_lr1e4/`，不覆盖低 LR 分支。

为判断高 LR 是否被既有 `clip_grad_norm_=1.0` 抵消，日志新增平均 pre-clip grad norm 和裁剪步占比；该改动不改变优化数学。若固定样本未在 1e-4 完成前准备好，再从同 seed 的 step 0 运行 `LR=5e-5`。

用户已安排 12k 完成后自动启动另一条独立的 `LR=1e-4`、随机初始化、目标 30k 的长程实验。它不从 12k checkpoint 续跑，使用新输出目录 `ckpts/plus_ja_sft_v4vf_lr1e4_30k/`，由 `run_v4vf_lr1e4_30k_after12k.sh` 等待上游 tmux session 30k 长程结果

按用户修正后的计划，12k 完成后从随机初始化 step 0 新开 `LR=1e-4`、目标 30k 的独立实验；没有读取 12k checkpoint，输出目录为 `ckpts/plus_ja_sft_v4vf_lr1e4_30k/`。

最终 Eval：Loss=`2.4757`、FlowA=`0.3667`、FlowB=`0.9928`、CKA=`0.1763`。训练后段 FlowB 长期在约 `0.99` 附近振荡，没有数值发散；checkpoint 的 model、EMA、optimizer 均存在，`global_step=30000`，全部模型浮点 tensor 有限。

同协议对照：V4fg 在 15k FlowB=`0.9886`，V4f official-base 在 30k FlowB=`0.9066`。因此随机初始化 + 1e-4 已达到 V4fg 的 FlowB 平台附近，但仍明显落后 V4f official-base；仅凭 loss 不能推断文本、旋律和人耳质量。

## 感知门禁结论

用户实际试听确认：V4vf（随机初始化 30k + 官方 VAE）和 V4vfg（V4vf 30k 起点、适配 285k online VAE 10k）均存在大量噪音，未达到可用歌声质量。该现象跨越两个正确绑定的 VAE 配置，不能用单一解码器错配解释。

因此本分支最终结论为：随机初始化 DiT 虽可在训练指标上收敛，甚至使 FlowB 接近部分 VAE 适配实验的平台，但未学到可用的声学生成分布。V4vf 感知门禁失败，不建议继续延长训练或以其为起点推进 V4Pvf；后续应回到 Official base 起点的 V4Pf 路线。
