## 2. 当前已确认事实

1. SOFA `JPN_Test2_Plus` 训练侧句级对齐有效：V4f 24k 在固定 120 首评测上，文本命中分从 V4c 的 `0.409` 提升到 `0.473`。
2. 四个文本长度桶均有提升，但 `30+` 桶仍只有 `0.171`，长音频咬字崩坏尚未解决。
3. 当前训练按每个 Phrase 的起点放置 text tokens；正式推理只有 A 区起点和整个 B 区起点，后续句子没有独立锚点。
4. 当前训练样本总时长上限为 30 秒；实际 B 区中位数约 16.9 秒，训练已经大量覆盖 15–25 秒 B 区。简单提高 `max_duration` 不能解释或解决当前长音频问题。
5. 当前 A/B 来自同一条target singer音频的连续前后段；实际工作流通常是target singer参考 A + 无关旋律源 B，存在 A/B 来源上的训推差异。
6. 用户试听观察：V4f 24k 文本跟随更强、旋律跟随略弱；短音频疑似改善明显；特定长音频仍会出现旋律小崩、咬字大崩；美学仍未达到可用。

## 4. 编写纪律

- 工程实验与理论分析分开，避免理论指标替代生成质量。
- 所有训练消融从相同底模、相同数据清单、相同随机种子开始。
- PER 只评价文本命中；旋律、身份和美学必须独立记录。
- 训练时使用的信息，必须检查推理时能否以同分布方式获得。
- 完整 B 区金标 latent 不得伪装成可用条件；任何 B-cond 都必须排查答案泄漏。

## 5. 不训练的推理侧实验

> 本章先于所有新训练执行。目的不是证明某种架构更先进，而是用现有 checkpoint 判断当前故障有多少来自推理条件构造。

### 5.1 当前缺口

V4f 训练时，每个 Phrase 的 tokens 按其 SOFA `start` 放入对应帧；当前正式推理只有两个起点：

```python
lrc_start_times = [0.0, ref_len / VFR]
lrc_lines = ["", target_text]
```

因此 B 区全部 tokens 连续堆在 B 区开头。文本中加入 `|` 不能解决该问题：当前 `align_lrc_sentence_level()` 会在有时间戳的分支中把 `|` 替换为空格，仍然只有一个 B 区锚点。

这构成明确的训推差异，并与以下现象一致：

- V4f 第一句文本跟随增强；
- 后续句子离 B 区开头越远，越容易失去文本位置提示；
- 长音频更容易出现旋律小崩、咬字大崩；
- 固定 120 首中，V4f 的 `30+` 桶虽有改善但仍然很差。

### 5.2 I0：当前整段文本基线

保持当前正式推理不变：

- B 区整段文本只有一个起点；
- `steps=32`；
- `cfg=3.0`；
- checkpoint、参考音频、旋律音频、seed 全部固定。

I0 是后续推理实验的唯一基线。不得用不同 CFG、不同 seed 或不同参考音频替代它。

### 5.3 I1：逐句起点推理

新增独立实验入口，使推理显式接收：

```text
sentences: [句1, 句2, ...]
sentence_start_times: [t1, t2, ...]
```

内部构造：

```python
lrc_start_times = [0.0] + [ref_duration + t for t in sentence_start_times]
lrc_lines = [""] + sentences
```

要求：

- 时间均相对 B 区旋律音频起点定义；
- A 区追加静音时，统一计入 `ref_duration`；
- 每句 tokens 使用现有 tokenizer，不另换 G2P；
- 句子起点发生 token 重叠时，沿用现有“向后推迟”规则并记录次数；
- token 溢出时明确报错，不静默截断；
- 先建立独立实验脚本，不修改正式推理入口。

第一轮使用已有 SOFA 数据中的 Phrase 起点，不使用 Gold，也不运行新的自动对齐器。目的只是回答：当推理获得与训练同等级别的句级锚点时，现有 V4f 能否利用它。

### 5.4 I2：句级起点扰动

I1 有效后，再测试推理时间戳误差容忍度：

- `±0.1s`；
- `±0.3s`；
- `±0.5s`；
- 如有必要增加 `±1.0s` 失败边界。

每次扰动固定随机种子，并保持句子顺序单调。该实验回答实际工作流是否必须依赖精确人工标注，以及未来自动句界工具需要达到什么精度。

I1 无效时不做 I2，因为此时测鲁棒性没有意义。

### 5.5 checkpoint 对照

至少比较：

| 模型      | I0 当前整段文本 | I1 逐句起点 | 作用                              |
| ------- | --------: | ------: | ------------------------------- |
| V4c 24k |        必做 |      必做 | 判断旧模型是否也能利用句级锚点                 |
| V4f 24k |        必做 |      必做 | 判断 SOFA 训练是否增强句级锚点利用能力          |
| 官方底模    |        选做 |      选做 | 观察旋律、美学和长序列稳定性，不与日语 PER 作绝对公平比较 |

核心交互是：

```text
(V4f I1 - V4f I0) - (V4c I1 - V4c I0)
```

若 V4f 从 I1 获益明显大于 V4c，说明 SOFA 训练已经学会句级位置结构，只是正式推理没有提供对应信息。

### 5.6 分层诊断集

先不跑完整 120 首，建立小型固定诊断集：

- 短音频：10 条；
- 中等长度：10 条；
- `30+` 长文本：20 条；
- 用户实际工作流中的固定抽风输入：单独加入，不替换上述样本；
- 尽量覆盖单句、多句、快歌、慢歌、长音、句间短停顿。

每条保存：

- 输入路径与文本；
- 句子及起点；
- checkpoint；
- seed、CFG、steps；
- I0/I1 输出 wav；
- ASR 文本与项目 PER 命中分；
- 旋律跟随结果；
- 人耳备注。

小集出现明确方向后，再在固定 120 首清单上做完整配对。不得只挑改善样本汇报。

### 5.7 评价轴

推理实验至少分开记录：

1. **文本命中**：沿用现有 large-v3 → kana → `max(0, 1-CER)`；
2. **后段文本完整性**：按句检查后续句是否被识别，不只看整段平均；
3. **旋律跟随**：使用同一 F0 指标和同一有效音高 mask；
4. **身份**：target singer参考与输出的 speaker similarity，仅作辅助；
5. **美学/可用性**：用户盲听或至少隐藏版本名的 A/B；
6. **抽风率**：固定输入中出现严重旋律或咬字崩坏的比例。

不得用 PER 单独决定 I1 是否可用。如果文本提高但旋律或美学显著恶化，应判断为条件竞争，而不是无条件通过。

### 5.8 结果分支

| 结果                  | 解释                                | 下一步                              |
| ------------------- | --------------------------------- | -------------------------------- |
| I1 显著改善长音频，旋律无明显退化  | 主要问题是推理缺少句级锚点                     | 固化句级推理接口，进入实际句界获取方案              |
| I1 文本改善、旋律继续变弱      | text 与 melody 条件竞争                | 做推理条件强度/CFG 小型实验，不立即重训           |
| I1 只改善第一、二句，后段仍崩    | 长序列 attention 仍可能涣散               | 进入句内软窗口/DiTSinger attention mask |
| I1 基本无效             | 模型没有有效利用句级位置，或问题不在 text placement | 检查训练 token 放置、长序列表示和 A/B 来源      |
| V4f 从 I1 获益，V4c 不获益 | SOFA 训练有效但推理接口未兑现收益               | 句级推理成为 V4f 正式接口                  |
| V4c/V4f 都获益         | 推理接口是跨版本共同缺陷                      | 先修接口，再评价训练路线                     |

### 5.9 本章停止条件

满足以下条件才进入训练消融：

- I0/I1 独立脚本可复现；
- 固定诊断集已保存；
- V4c/V4f 使用完全相同输入完成配对；
- 至少完成一次后段逐句检查；
- 已明确句级推理能解决多少、不能解决什么；
- 没有把时间戳来源误当成模型能力本身。

## 6. A/B 来源与 YM-SVC 草稿条件

### 6.1 当前同源 A/B 的含义

当前 V4c/V4f 从同一条target singer音频中选择一个句界切点：

```text
A = 原音频前段
B = 原音频后段
```

A 区提供真实 latent，B 区 `cond=0`；B 区旋律由同一音频提取，训练目标也是该音频后段。该构造保证监督真实、声音连续，但同时提供了实际推理中通常不存在的相关性：

- 同一歌曲与调性；
- 同一录音、麦克风、混响、响度；
- 同一演唱状态与风格；
- A 是 B 的自然前文；
- A 的歌曲上下文可能帮助模型猜测 B，而不仅提供歌手身份。

实际工作流更接近：

```text
A = target singer参考
B旋律 = 与A无关的歌曲或其他歌手
目标歌词 = 用户指定文本
```

因此 A/B 来源是独立于时间戳之外的训推差异。

### 6.2 X0：同源连续基线

X0 即当前 V4f 数据构造，作为 A/B 来源消融基线：

- A、B 来自同一文件；
- 按句界切分；
- B 无任何声学 cond；
- B target 为真实target singer音频；
- SOFA 句级 token 放置保持不变。

后续版本不得同时改变时间戳粒度、loss、LR 或数据规模。

### 6.3 X1：同target singer异曲 A/B

构造：

```text
A = target singer音频甲中的完整句界片段
B = target singer音频乙中的完整句界片段
训练 target = B 本身
```

A 与 B 均为target singer，因此 B target 仍是真实监督；不同文件迫使模型把 A 主要用于身份/音色，而不能依赖歌曲连续性。

建议约束：

- A、B 必须来自不同原始文件；
- 优先来自不同歌曲或不同 BV cluster；
- A 约 5–8 秒；
- B 至少 8–10 秒，优先覆盖 15–25 秒；
- 总长度保持在当前模型可承受范围；
- A、B 均在 Phrase 边界裁剪；
- B 的 Phrase 时间戳在拼接后统一平移；
- A 后加入与正式推理一致的静音长度；
- 做响度范围控制，但不把两个录音强行处理成完全相同；
- 保存 pair manifest，保证训练/测试可复现并避免测试歌曲泄漏。

X1 主要验证：

- A 是否真正只提供身份；
- B 是否更依赖自身 midi 与 text；
- 跨歌曲旋律控制是否更稳定；
- 同源连续捷径是否造成当前抽风或旋律/文本竞争。

### 6.4 为什么暂不直接使用“其他歌手 B”监督

理想训练样本是：

```text
A：target singer参考
B输入：其他歌手的旋律源
B target：target singer按同一旋律、同一歌词演唱
```

但目前没有大规模平行 target。若 B midi 来自其他歌手，而 target 是不对应的target singer音频，会制造旋律标签错误。除非满足以下之一，否则不进入正式训练：

- 找到同曲、同段、可时间映射的平行翻唱；
- 使用明确的 MIDI/音符控制并证明与 target 对应；
- 获得可信的target singer伪 target；
- 建立经过人工核验的平行小集。

因此近期“异源 A/B”专指同target singer不同文件，不等于其他歌手 B 平行训练。

### 6.5 C0：无 B-cond 基线

C0 即当前 B 区：

```text
cond_B = 0
```

模型必须根据噪声、text 与 midi 完成整个 B 区。其优点是没有答案泄漏，缺点是生成难度高，可能丢失音色、美学和长程声学稳定性。

### 6.6 C1：完整 YM-SVC B-cond

候选流程：

```text
B旋律源 → YM-SVCtarget singer转换 → VAE latent → 填入整个B区cond
```

该路线只适合优先验证“同歌词换音色”场景。对于改词翻唱，YM-SVC 输出仍包含源歌词咬字；完整 B-cond 会与目标 text 冲突，并可能让 DiT 直接复制 SVC 草稿。

风险：

- 重新出现类似 V1 的答案捷径；
- text 条件被 B-cond 压制；
- 训练 PER 很好、改词推理失败；
- 输出上限被 YM-SVC 瑕疵限制；
- 训练时用金标生成的 SVC-cond 比实际推理干净，产生新的分布差异。

所以 C1 不是当前改词主线，只能作为能力边界或同歌词场景对照。

### 6.7 C2：稀疏/弱化 YM-SVC 草稿 cond

C2 的目标不是提供答案，而是提供不完整的target singer声学草稿：

```text
B旋律源 → YM-SVC → 草稿latent → 破坏细粒度咬字信息 → 随机暴露给B区
```

候选弱化方式从简单到复杂：

1. 随机暴露少量连续短岛；
2. 随机 frame mask，只保留 5%–30%；
3. 时间下采样后再插值；
4. 加噪声或幅度衰减；
5. 低通/平滑 latent，尽量保留音色与声学轮廓、破坏音素细节；
6. 随机时间偏移，防止逐帧复制。

第一轮只选一种最简单方式，例如固定分布的随机短岛，不同时组合多种破坏。

训练时的草稿生成必须逼近推理分布。优先候选：

```text
真实target singerB
→ 先通过音色扰动或伪源歌手转换
→ 再用YM-SVC转回target singer
→ 得到带真实转换瑕疵的草稿
```

直接用金标 B 自身经过近乎恒等的转换，可能让草稿过于接近答案，应先量化它与 target latent 的相似度。

### 6.8 B-cond 的泄漏审计

任何 C1/C2 训练前都必须完成以下检查：

- 将 B-cond 单独送入模型、关闭 text/midi，输出是否仍能还原歌词；
- B-cond 与 target latent 的逐帧 cos/MSE；
- B-cond 的 ASR 是否已包含目标歌词；
- 随机替换目标 text 后，输出是否仍跟随 B-cond 原歌词；
- 推理时可获得的 B-cond 与训练 B-cond 是否来自相同处理链；
- 对时间平移、mask 或下采样后，咬字信息保留到什么程度；
- C2 的改善是否只是 SVC 本身，而非 SVS 学会修复。

若关闭 text 后仍可稳定恢复目标歌词，说明 cond 太强，不适合作为改词训练条件。

### 6.9 X/C 二乘二工程消融

以相同官方 base、SOFA 数据和 V4f 配方建立：

| 版本   | A/B来源 | B-cond  | 回答的问题              |
| ---- | ----- | ------- | ------------------ |
| X0C0 | 同源连续  | 无       | 已有 V4f 基线          |
| X1C0 | 同target singer异曲 | 无       | 去掉连续性捷径是否改善泛化      |
| X0C2 | 同源连续  | 稀疏SVC草稿 | 草稿 cond 是否改善声学与稳定性 |
| X1C2 | 同target singer异曲 | 稀疏SVC草稿 | 两项是否互补             |

执行纪律：

- 先完成 X1C0 和 X0C2 两个单变量版本；
- 只有至少一个单变量有效，才训练 X1C2；
- 不重新训练 X0C0，复用 V4f 时必须确认底模、步数和配方可比；若不可比，则四版统一短程重跑；
- 第一筛建议短程 checkpoint，不直接四版 30k；
- 同一固定诊断集同时评价 PER、F0、身份、美学和抽风率。

### 6.10 本章决策规则

| 现象                    | 结论                  |
| --------------------- | ------------------- |
| X1C0 改善跨歌曲与抽风率，PER不退化 | 异曲 A/B 纳入正式 P2      |
| X1C0 旋律更稳但身份/音质下降     | A 比例或拼接分布需调整        |
| X0C2 美学提升且改词仍跟随 text  | 稀疏草稿路线成立            |
| X0C2 同歌词好、改词仍唱旧词      | B-cond 咬字泄漏，降低暴露或终止 |
| C2 结果等同直接 YM-SVC      | SVS 没有提供额外价值，不进入主线  |
| X1C2 才有效而单变量无效        | 优先怀疑实验噪声，不直接接受交互结论  |

## 7. 文本时间信息粒度

### 7.1 需要区分的四种粒度

当前讨论中的“字级时间戳”可能混指不同对象：

1. **句级**：每个 Phrase 一个起点，当前 SOFA/V4f 主路线；
2. **句内软窗口**：token 只能关注或放置在对应句的局部范围，但不指定唯一帧；
3. **摩拉/音素级**：每个可发音单位有边界；
4. **书写字符级**：汉字、假名字符直接对应时间。

日语书写字符不天然等于声音单位：一个汉字可对应多个音，促音、拨音和长音也需要独立处理。因此近期不把“书写字符硬时间戳”作为正式路线。若进入细粒度实验，应以当前 tokenizer 对应的音素/摩拉序列为准，并先验证 SOFA/G2P token 映射一致。

### 7.2 T0：整段单锚点

T0 是当前推理状态，所有 B 区 tokens 在 B 起点连续放置。它只作为失败基线，不是未来训练目标。

### 7.3 T1：句级硬起点

每句有明确起点，句内 tokens 从该起点连续排列。优点：

- 与 V4f 训练方式接近；
- 实际推理较容易获得；
- 不强制复制句内每个字的 timing；
- 保留target singer拖音、抢拍和表达自由。

T1 是当前主路线。先通过第 5 章推理实验验证，再决定是否需要更细粒度。

### 7.4 T2：句内软窗口

T2 不要求每个 token 对应唯一时间，而是为每句建立允许范围：

```text
句i tokens 主要在 [句i起点 - margin, 句i终点 + margin] 内作用
```

实现候选：

- 对 text-to-audio attention 添加局部 mask；
- 对 token embedding 的帧级放置加入扩展窗口；
- 允许相邻句窗口少量重叠；
- 对长音和句尾拖音保留右侧余量。

T2 对应 V5 中的 DiTSinger 字符级 attention window 储备，但此处强调“软约束”，目标是防止第三句以后跨句注意力涣散，而不是复制源歌手逐字 timing。

触发条件：

- T1 明显优于 T0，但长音频后段仍崩；或
- 后续句 ASR 串句/错槽明显，且句级起点本身正确。

### 7.5 T3：音素/摩拉级硬时间戳

T3 将每个音素或摩拉放在精确帧附近。可能提高咬字位置和 PER，但风险最大：

- 压缩句内表达自由；
- 复制旋律源歌手 timing；
- 推理时难以为改词获得可靠细粒度时间；
- SOFA 音素与项目自定义 token 不完全同构时会产生伪精确；
- PER 可能上升而美学、target singer唱法下降。

只有满足以下条件才进入 T3：

- T1/T2 仍无法解决明确的句内错位；
- SOFA TextGrid 音素到项目 token 的映射已经逐项验证；
- 推理侧能获得同分布的音素/摩拉时间；
- 有专门的人耳表达性 A/B，而非只看 PER。

### 7.6 时间抖动

时间抖动不是替代时间戳，而是让模型对推理误差鲁棒。应建立在选定粒度之后：

- T1：对句起点施加小幅扰动；
- T2：扰动窗口边缘与中心；
- T3：避免对每个音素独立大幅抖动造成顺序破坏。

第一轮不同时改粒度和抖动。应先比较 T1 无抖动，再单独加入推理需求对应的误差范围。

### 7.7 粒度决策顺序

```text
T0 整段单锚点
→ T1 句级起点
→ 若后段仍跨句漂移：T2 句内软窗口
→ 若仍有可定位的句内音素错位：T3 音素/摩拉硬时间戳
```

越精确不等于越好。每提高一级粒度，都必须证明上一层不能解决问题。

## 8. 与 V5 P1/P2/P3 的合并

### 8.1 对 V5 已被证伪或修正的部分

当前证据已经否定：

- “FlowB≈0.90 主要由对齐噪声造成”；
- “重对齐应使 FlowB 跌破 0.88”；
- “SOFA 必须先经过 A7 小窗口才可用”；
- “P0 只要完成就会自然解决唱功/浴室感”。

V4f 使用 SOFA 后 FlowB 平台仍在，但 PER 明显提高。因此应把 P0 的真实结论改为：

> 句级重对齐提高了文本条件的可学习性，但不是 FlowB 平台、长音频崩坏和美学退化的唯一根因。

### 8.2 仍然成立的 V5 原则

以下原则继续成立：

- 训练与推理的 B 区条件分布必须一致；
- Gold 只用于评价，不参与实际时间戳生成；
- 日语发音先验不足与时间戳错误是不同问题；
- 浴室感/唱功退化需要独立于 PER 处理；
- 词级/音素级精确放置可能损害表达自由；
- GRPO、ΔFM、GradNorm、CPC 不能替代基础条件结构修复。

### 8.3 P1：日语 TTS 接地

P1 解决的是模型是否具备稳定的日语发音先验，而不是歌词何时出现。SOFA 提高 PER 不能证明 P1 已无必要。

P1 的触发证据包括：

- 句级推理正确后仍有短句发音错误；
- 相同 token 在不同旋律中反复误读；
- 日语 embedding/文本编码层相对官方底模发生异常漂移；
- 错误不随时间戳改善而改善。

P1 成本高，不应在低成本推理实验完成前立即启动。若启动，应保留 CN/EN 防遗忘检查，并明确哪些层参与训练。

### 8.4 P2：正式歌唱 SFT

未来 P2 不再简单等于“SOFA 数据重跑”，而应整合已通过的单变量结果：

- SOFA 句级对齐；
- 训练/推理同构的 T1 或 T2；
- 经验证的时间抖动；
- X0/X1 中胜出的 A/B 来源；
- C0/C2 中胜出的 B-cond 策略；
- SPFM 或其他残余错标过滤；
- 明确的早停与底模漂移监控。

未通过单变量验证的模块不得同时塞入正式 P2，否则无法判断成败原因。

### 8.5 P3：唱功、身份和美学

P3 与文本命中分开。候选路径：

- 早停和参数漂移控制；
- VAE decoder 微调；
- 官方底模 replay；
- 子中心 speaker/identity 表示；
- SVC teacher 或草稿 cond；
- 必要时独立的身份/美学损失。

若 P2 PER 提升而美学仍不可用，不得继续靠更精确时间戳解释；应转入 P3。

### 8.6 后置增强

以下路线只有基础实验完成后再启用：

- DiTSinger attention window：T1 后仍有后段跨句漂移；
- 音素/摩拉硬时间戳：T2 后仍有句内错位；
- ΔFM/GradNorm/CPC：基础条件正确后优化训练目标；
- GRPO：SFT 文本命中已较高且 reward 不再被结构错误主导；
- 完整 SVC 后处理：作为系统级组合，与端到端 SVS 能力分开评价。

## 9. 工程消融矩阵

### 9.1 消融目标

工程消融只回答能够改变产品路径的问题：

- 句级推理是否必要；
- 同target singer异曲 A/B 是否必要；
- 稀疏 SVC 草稿 cond 是否有净收益；
- 句内软窗口是否解决长序列；
- P1 日语接地是否解决剩余发音错误；
- 美学退化应由早停、VAE 还是 replay 处理。

工程消融不追求穷举所有组合。每个版本必须对应明确决策。

### 9.2 第 0 层：无需训练

| 编号 | 模型      | 推理放置  | 目的                 |
| -- | ------- | ----- | ------------------ |
| E0 | V4c 24k | T0    | 旧基线                |
| E1 | V4c 24k | T1    | 旧模型能否利用句级锚点        |
| E2 | V4f 24k | T0    | 当前新模型基线            |
| E3 | V4f 24k | T1    | SOFA 训练收益能否在同构推理兑现 |
| E4 | V4f 24k | T1+扰动 | 推理句界误差容忍度          |

只有 E3 对长音频仍不足时，才进入 T2。

### 9.3 第 1 层：数据/条件单变量短程训练

所有版本从同一官方 base 开始，使用同一固定训练清单、eval 清单、随机种子和配方：

| 编号  | A/B   | B-cond   | 时间放置 | 变量         |
| --- | ----- | -------- | ---- | ---------- |
| E10 | X0 同源 | C0 无     | T1   | 统一短程基线     |
| E11 | X1 异曲 | C0 无     | T1   | 仅改变 A/B 来源 |
| E12 | X0 同源 | C2 稀疏SVC | T1   | 仅增加草稿 cond |

建议阶段：

- 6k：早期能力与灾难性失败筛查；
- 12k：确认趋势；
- 24k：只给胜者或必须比较的版本。

短程版本不能只看 eval loss。每个阶段必须在同一固定生成集评价。

### 9.4 第 2 层：交互与时间窗口

只有第 1 层提供正向证据后才运行：

| 编号  | 条件               | 触发条件                    |
| --- | ---------------- | ----------------------- |
| E20 | X1 + C2 + T1     | E11、E12 至少一项有效，且有合理互补假设 |
| E21 | 胜出 A/B/cond + T2 | T1 后仍有长音频跨句漂移           |
| E22 | 胜出配置 + 时间抖动      | 已测出实际句界误差范围             |

若两个单变量均无效，不运行 E20；不能期待两个失败模块组合后自动成功。

### 9.5 第 3 层：P1/P2 与美学路线

| 编号  | 版本                       | 目的             |
| --- | ------------------------ | -------------- |
| E30 | P1 日语接地模型                | 测试发音先验，而非旋律/美学 |
| E31 | P1 → 胜出 P2 SFT           | 正式 V5 主模型      |
| E32 | E31 + 早停/低漂移策略           | 检查浴室感是否来自参数漂移  |
| E33 | E31 + VAE decoder 路线     | 检查解码器声学上限      |
| E34 | E31 + replay/identity 增强 | 检查官方先验与target singer身份保持  |

E32–E34 不应同时启动。先根据试听和参数分析确定最可能的根因。

### 9.6 官方模型在消融中的角色

官方模型不是公平的日语 PER 基线，但它有三个用途：

1. 作为参数变化的共同原点；
2. 提供旋律、美学、长序列稳定性的先验参照；
3. 判断某项能力是微调新学到，还是官方模型原本已有、微调后丢失。

对比集合至少包括：

```text
Official base
V4c 24k
V4f 24k
新增短程消融 checkpoint
```

### 9.7 共同评价表

每个工程版本统一保存：

- 总 PER 与长度分桶 PER；
- 后续句逐句命中；
- F0/旋律跟随；
- speaker similarity；
- 抽风率；
- 人耳美学与可用性；
- 训练/推理耗时和显存；
- 参数相对官方底模的变化摘要。

任何版本只有 loss 改善、生成不改善，都不能晋级。

### 9.8 训练公平性

- 相同官方 base；
- 相同 checkpoint 保存步数；
- 相同数据数量或显式记录采样差异；
- 相同 world size、有效 batch 和精度；
- 相同 LR schedule；
- 相同评测 seeds；
- 不因某版失败临时更换 CFG 后再比较；
- 所有 manifests 和脚本随结果保存。

## 10. DiT 多层分层消融与权重变化分析

> 后续修正：Official 主要处于 CN/EN 分布，本章涉及“恢复官方层”的内容只能作为探索探针，不能直接解释为恢复 JP 美学。正式对照优先使用早期 JP checkpoint；干预定义与执行顺序以第 15–16 章为准。

> 本章偏理论研究。它可以解释工程现象、帮助缩小训练层范围，但默认不阻塞第 5 章的句级推理实验。

### 10.1 研究问题

希望回答：

1. 日语发音能力主要写入哪些 DiT 层；
2. SOFA 对齐主要改变早层 token/位置绑定，还是中后层声学生成；
3. 旋律跟随变弱对应哪些层偏离官方底模；
4. 第一句文本增强是否集中在特定层；
5. 浴室感/厚重是否与后层、输出层或 VAE 无关的 DiT 漂移相关；
6. 是否可以只训练部分层，保留官方旋律和美学先验。

### 10.2 比较 checkpoint

最低集合：

- 官方 YingMusicSinger base；
- V4c 24k；
- V4f 24k；
- V4f 6k/12k/18k/24k/30k 中可用 checkpoint；
- 未来 P1 日语接地 checkpoint；
- 未来工程消融胜者。

V4c 与 V4f 的训练数据不同，因此层变化只能与行为相关联，不能自动解释为因果。真正的因果结论需要冻结/替换层实验。

### 10.3 参数变化静态分析

按模块和层统计相对官方 base：

- 参数 L2 差；
- 相对 L2：`||W_new-W_base|| / ||W_base||`；
- cosine similarity；
- 最大绝对变化；
- 参数更新方向在 V4c/V4f 间的 cosine；
- LayerNorm scale/bias 漂移；
- attention Q/K/V/O；
- FFN/ConvNeXt/text embedding；
- midi 输入投影、text 输入投影、cond 投影；
- 最终 norm 与 output projection。

结果以层号曲线和模块表保存，但不把“变化大”直接解释为“负责该能力”。

### 10.4 激活变化动态分析

在固定输入集上，对官方/V4c/V4f 捕获每层 hidden states：

- A 区与 B 区分开；
- B 区第一句、中段句、末句分开；
- 短音频与长音频分开；
- T0 与 T1 推理分开；
- 正常样本与抽风样本分开。

候选指标：

- 层间/模型间 CKA；
- hidden state cosine；
- token位置与hidden的线性可分性；
- midi embedding 与 hidden 的 CKA；
- A-cond 对 B hidden 的影响；
- attention entropy 与跨句注意力比例；
- 长度增加时表示相似度的衰减。

重点不是再造一个总分，而是寻找行为突变首次出现在哪一层。

### 10.5 分层冻结训练消融

将 DiT 粗分为：

```text
Early：输入绑定与局部表示
Middle：文本/旋律/cond 融合
Late：声学细化与输出
```

具体层数应根据模型实际 block 数等分或依据静态/动态分析确定，不预先假定三段功能。

候选训练版本：

- 只训练 text embedding + early；
- 只训练 middle；
- 只训练 late + output；
- 训练 early+middle，冻结 late；
- 冻结 early，训练 middle+late；
- 全量训练基线。

该组属于昂贵实验。先以 3k–6k 短程观察能力方向，不直接训练完整周期。

### 10.6 Layer transplant / 权重拼接

比重新训练更便宜的因果探针：

```text
以 V4f 为主体，将某一层段替换回官方或 V4c 权重
```

候选：

- V4f early + 官方 middle/late；
- 官方 early + V4f middle/late；
- V4f 保留 text embedding，仅恢复官方 late；
- V4f 保留 SOFA 相关前层，恢复 V4c/官方旋律相关层。

每次只替换连续层段，并在同一诊断集生成。若恢复某层段后旋律改善而 PER 保持，说明该层段可能承载被破坏的官方先验。

风险：不同层共同适配后直接拼接可能产生接口失配。因此 transplant 先作为探针；若短暂灾难性失败，不能立即证明该层无关。

### 10.7 层级 LoRA/Adapter 探针

若全参数分层训练成本过高，可在不同层段放置等参数量 LoRA/Adapter：

- early-only；
- middle-only；
- late-only；
- text-path only；
- midi-path only。

这回答“少量可塑性放在哪里最有效”，但 LoRA 容量限制使其不能直接替代全量微调结论。

### 10.8 梯度与更新过程分析

未来短程训练保存：

- 各层 grad norm；
- text/midi/cond 输入投影 grad norm；
- FlowA/FlowB 分别反传时的层级梯度；
- PER好样本与抽风样本的梯度差异；
- SOFA 与旧时间戳 batch 的梯度方向 cosine；
- 短/长音频 batch 的梯度冲突。

这可以判断长音频是否在训练中产生与短音频相反的更新方向，以及 text 增强是否牺牲 melody 通路。

### 10.9 理论分析与工程结论的边界

以下说法不能仅凭权重图得出：

- 某层变化最大，所以某层负责日语；
- 某层 CKA 下降，所以它造成浴室感；
- V4f 某层更接近官方，所以美学必然更好；
- 梯度冲突存在，所以必须使用 GradNorm。

至少需要 layer freeze、transplant 或等价干预才能提出因果判断。静态权重和激活分析主要用于提出下一组小型干预。

### 10.10 理论工作优先级

建议顺序：

1. 先完成无需训练的权重差与固定输入激活抓取；
2. 对 T0/T1、短/长、正常/抽风做分层比较；
3. 选择 1–2 个最有信息量的 layer transplant；
4. 只有 transplant 给出明确方向，再训练分层冻结版本；
5. 将结果用于 P1/P2 的冻结策略，而不是单独追求论文式图表。

### 11.2 近期第一任务：T1 句级推理

交付物：

- 独立推理脚本；
- 句子+起点输入格式；
- token 重叠和溢出日志；
- 固定诊断集 manifest；
- V4c/V4f 的 T0/T1 输出；
- PER、后段逐句、旋律、人耳对照。

预计成本：

## 13. 当前结论摘要

1. SOFA 训练侧对齐已证明能提高文本命中，但未解决 FlowB 平台、长音频崩坏和美学问题。
2. 当前最明确、最低成本的结构缺口是推理只有一个 B 区文本锚点；T1 逐句推理必须先做。
3. 当前 30 秒训练上限已经覆盖几乎全部数据，简单加长不会增加有效长音频训练材料。
4. 同target singer异曲 A/B 是合理的下一训练单变量；其他歌手 B 缺少平行 target，暂不能直接监督。

6. 时间粒度按 T1句级 → T2软窗口 → T3音素/摩拉硬时间戳递进，不追求无证据的过度精确。
7. 工程主线与 DiT 理论分析分开；理论工作优先用静态差、激活和 layer transplant 缩小假设，再决定分层训练。

## 15. 语言域混淆下的可信对照路线

### 15.1 为什么不能简单比较 Official 与 V4f 美学

官方底模主要处于 CN/EN 场景，当前模型处于 JP 单歌手场景。两者之间同时变化：

- 语言：CN/EN → JP；
- 日语 token/embedding 从未训练或训练不足 → 经过日语微调；
- 数据规模与多样性：官方海量多分布 → target singer约99h单歌手；
- 任务：通用歌唱 → target singer日语翻唱；
- 对齐与文本放置方式；
- 训练步数和参数漂移。

因此以下推断不成立：

```text
Official听感好，V4f听感差
→ V4f一定破坏了Official美学
```

V4f 与 Official 的参数距离也不能直接作为美学退化证据，因为一部分变化可能是学习日语所必需。

### 15.2 Official 对照仍然能回答什么

Official 仍有三个用途：

1. 参数共同原点：描述哪些模块变化；
2. CN/EN 防遗忘：检查原有能力是否丢失；
3. 分层替换探针：测试换回某层后行为如何变化。

Official 不能直接作为 JP 美学优劣的公平基线。Official layer replacement 的结果必须标注语言域混淆，不能单独作为最终冻结方案依据。

### 15.3 第一类干净对照：日语 VAE 复刻


- 雪花声；

- 约20秒局部崩坏是否已存在。

## 16. DiT 分层干预的精确定义

### 16.1 主线 A：Residual Bypass

Transformer block 通常具有残差形式：

```python
x_out = x_in + delta(x_in)
```

“不加载/移除某层”的正确近似是：

```python
x_out = x_in
```

即令该 block 的 residual contribution 为 0。它回答：

> 缺少这一层新增的计算，模型会失去什么？

不应使用：

```python
x_out = 0
x_out = 1
```

因为这会清空前层信息或注入常数分布外激活，不等于移除该层。

### 16.2 连续缩放消融

在 bypass 基础上定义：

```python
x_out = x_in + alpha * delta(x_in)
```

- `alpha=1.0`：原模型；
- `alpha=0.5`：贡献减半；
- `alpha=0.0`：完整 bypass；
- `alpha>1.0`：仅作敏感性探针。

它比单点 bypass 更适合判断某层是“必要”还是“强度过大”。

### 16.3 主线 B：Checkpoint Layer Replacement

保持 V4f 其余参数不变，替换连续层段：

```text
V4f block range
→ Official 对应层
→ V4c 对应层
→ V4f早期JP checkpoint对应层
```

可信度与用途不同：

- Official：语言域混淆较大，只作探索探针；
- V4c：同为 JP，但数据/对齐路线不同；
- V4f早期 JP：同语言、同数据、同训练路线，最适合分析训练时间轨迹。

结果解释：

| 替换后现象     | 可能解释                |
| --------- | ------------------- |
| 文本下降、美学不变 | 被替换层可能承载 JP/text 能力 |
| 文本不变、美学改善 | 后期该层变化可能包含不必要声学退化   |
| 旋律恢复、文本保持 | 可能找到条件竞争层段          |
| 全面崩坏      | 层间共同适配或接口失配，不能简单定罪  |
| 几乎不变      | 层段影响弱或被残差/后层补偿      |

### 16.4 辅线 C：同尺度噪声替换

噪声不等于“不加载”。合理诊断形式：

```python
delta_noise = randn_like(delta) * delta.std()
x_out = x_in + delta_noise
```

它回答：

> 后续层需要该层产生的具体结构，还是只对相似幅度扰动敏感？

若 bypass 尚可而噪声崩坏，说明错误结构比没有结构更危险。噪声路线只作鲁棒性诊断，不用于最终模型选择。

### 16.5 0/1 Bernoulli 的位置

若“全0/1”指 mask：

```python
x_out = x_in + mask * delta
mask ∈ {0,1}
```

固定 `mask=0` 就是 bypass，固定 `mask=1` 就是原模型。随机 mask 相当于 inference stochastic depth，测试冗余性，但不适合第一轮，因为不同层组合难解释。

### 16.6 第一轮按层段，不逐层穷举

先确认实际 block 数，再粗分：

```text
Early / Middle / Late
```

第一轮最低矩阵：

| 编号 | 干预                      |
| -- | ----------------------- |
| D0 | 完整 V4f 基线               |
| D1 | Bypass Early            |
| D2 | Bypass Middle           |
| D3 | Bypass Late             |
| D4 | Official Replace Early  |
| D5 | Official Replace Middle |
| D6 | Official Replace Late   |

若整段 bypass 全部灾难性失败，改成每次 2–3 个连续 blocks 的滑动窗口，而不是立即逐层全扫。

### 16.7 第二轮优先早期 JP 替换

找到敏感层段后，优先：

```text
V4f 24k其余层
+ V4f 3k/6k/12k敏感层段
```

目标：在语言域一致的前提下，检查能否保留 24k 文本能力，同时恢复早期 JP checkpoint 的旋律或美学。

Official replacement 若改善，也必须再用早期 JP replacement 复核，避免把 CN/EN 层接口偶然效应误认为可迁移美学。

### 16.8 评价集与顺序

第一轮使用少量正常歌唱样本：

- 短音频；
- 长多句 + T1；
- sample02：可能有旋律代价；
- sample03/04：T1文本改善明显；
- 不使用 sample01 高噪说话腔作为正常质量主结论。

固定 checkpoint、输入、T1、seed、CFG、steps。记录：

- 是否能正常生成；
- 文本 PER；
- F0-CORR；
- 雪花、电音、浴室感；
- target singer身份与唱法；
- 是否在相同位置崩坏。

### 16.9 分层消融执行顺序

```text
1. 确认block数和模块命名
2. JP checkpoint静态权重轨迹
3. Early/Middle/Late bypass
4. Early/Middle/Late Official replacement（探针）
5. 敏感层段的早期JP replacement
6. 对敏感区域做2–3层窗口或逐层扫描
7. alpha缩放
8. 同尺度噪声与随机0/1 mask（后置鲁棒性实验）
9. 有明确因果迹象后才训练分层冻结版本
```

该路线的目的不是寻找一张“哪层最重要”的图，而是寻找可执行的能力分工：

- 哪些层承载日语文本；
- 哪些层影响旋律；
- 哪些层与美学退化同现；
- 是否存在可保留后期文本、恢复早期 JP 声学状态的层级组合。
