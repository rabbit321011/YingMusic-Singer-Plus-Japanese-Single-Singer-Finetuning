# V5-P 训练脚本交接导读

## 先看什么

正式 oracle 是 `package_v4c_finetune/train/train_v5p.py`；本分支的可读入口是
`package_v4c_finetune/train/train_v5p_simple.py`。阅读时先跳过哈希、RNG、checkpoint
序列化和分布式同步细节，沿着 `main()` 的主线看：参数校验 → 设备初始化 → 数据集 → 模型与
条件 → 训练循环 → eval/save。

## 一步训练做什么

```text
样本音频
  → frozen VAE latent
  → A/B 区切分
  → H/PUL 文本 placement
  → GAME-P cache / P embedding
  → DiT forward
  → FlowA + FlowB + CKA
  → backward / 梯度同步 / optimizer.step
  → CPU EMA、eval、checkpoint
```

- A 区提供参考音色 latent，MIDI 条件清零；
- B 区是需要生成的目标区域，使用 H/PUL 文本条件和 GAME-P 旋律条件；
- VAE、GAME teacher 和其他冻结模块不应产生训练梯度；
- V5-P 的正式谱系、路径和哈希以 `../V5-P正式训练计划.md` 为准。

## 单卡阅读重点

单卡通过不设置 `LOCAL_RANK` 进入 `world_size=1` 路径，并将
`--expected_world_size 1`。单卡 smoke 用来验证链路，不代表与四卡训练 bit-exact 等价。

## 哪些代码先不要改

`sync_gradients`、sampler cursor、EMA 更新、checkpoint metadata 和 SHA256 校验属于实验
可复现性基础设施。任何改动都必须在 `校验清单.md` 的回归项目中留下结果。
