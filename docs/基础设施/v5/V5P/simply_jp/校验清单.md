# simply_jp 校验清单

旧版正式脚本只读保留，作为 oracle；新版脚本不得在没有对照结果时替换正式入口。

| 编号 | 校验 | 通过标准 |
|---:|---|---|
| 1 | 语法与导入 | 编译、import、`--help` 全部通过 |
| 2 | 配置合同 | V5-P 参数、schema、路径和 SHA256 无未记录漂移 |
| 3 | 数据/cache | 音频、H/PUL、GAME、A/B、PAD、时长映射正确 |
| 4 | 单步训练 | forward、loss、backward、optimizer 全部完成且 finite |
| 7 | 单卡 checkpoint | GPU 7 上 step-1/10 可保存并通过 audit |
| 8 | 单卡 resume | global step、LR、optimizer、EMA、cursor 连续 |
| 9 | 60 秒样本 | 最长样本完成 forward/backward/save，无 OOM |

| 14 | 结构审查 | loss、mask、detach、EMA、保存语义未改变 |

## 结果记录

4、7、8、9、10、14、15；任何一项失败都不得把新版标为正式入口。

## Readability guard

`check_v5p_simple_structure.py` compares the readable copy with the oracle after removing
comments and docstrings. It must report an identical executable AST and the same function/class
definitions before any GPU run.

Current baseline:

```text
PASS: readable V5-P copy matches oracle executable AST
PASS: definitions=39
V5-P static tests: 6 passed
```
