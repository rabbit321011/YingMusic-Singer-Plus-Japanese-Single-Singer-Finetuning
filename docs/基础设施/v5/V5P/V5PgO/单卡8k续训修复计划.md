# 单卡续训修复计划

## 目标与边界

从已经完成 g 适配的 V5Pg20 EMA 出发，保留 GAME-P 的低带宽乐谱条件，去掉 B-only
hidden-state CKA 正则并提高 B 区 Flow 权重，检验普通演唱段的质感能否恢复。

这是一条已有模型上的目标函数修复路线，不重新进行 P-only 校准，也不从 V5-P 40k 重新适配
285k VAE。首轮目标固定为新增 8,000 次 optimizer update，不采用先训 1,000 步再决定是否
继续的预算方案；中途保留验证和轨迹听评，数值异常仍须停止。

B 区只能提供现有 P 路线允许的旋律信息。不得新增 continuous SOME、连续 F0、源歌手颤音、
滑音或声学 latent 条件；不能以恢复质感为由重新引入源歌手的演唱细节。

8k update 对应 128,000 次单样本 microbatch，不是 8,000 次单样本前向。保持有效 batch 16
不表示与旧四卡运行逐步 bit-exact。单卡减少并发占卡，不自动减少同等工作量的总 GPU 时；
实际速度和总耗时须由新配置实测。

本机 RTX 5070 Ti Laptop 的 12GB 显存不在本次单卡训练的已验证硬件范围内。

## 学习率日程

2026-09-21，用户确认 PgO 8k 使用以下独立学习率曲线。这里的 step 均指 optimizer
update，不是单样本 microbatch：

```text
0--1000:    linear warmup，0 -> 1e-5
1000--3000: hold，1e-5
3000--6000: cosine，1e-5 -> 3e-6
6000--8000: cosine，3e-6 -> 0
```

分段定义如下，连接点 `1000/3000/6000/8000` 采用连续值：

```text
0 <= s < 1000:
    lr(s) = 1e-5 * s / 1000

1000 <= s < 3000:
    lr(s) = 1e-5

3000 <= s < 6000:
    p = (s - 3000) / 3000
    lr(s) = 3e-6 + 0.5 * (1e-5 - 3e-6) * (1 + cos(pi * p))

6000 <= s <= 8000:
    p = (s - 6000) / 2000
    lr(s) = 0.5 * 3e-6 * (1 + cos(pi * p))
```

按连续曲线面积估算，累计 LR 暴露约为 `0.0475`；它约为历史 V5Pg 10k 的
`1.19x`、V5Pg20-HLR07 的 `0.35x`。该比较只描述学习率预算，不表示不同目标函数下的
实际参数位移等价。PgO 同时把 FlowB 权重从 2 提至 3 并关闭 CKA，因此门禁和正式日志须记录
裁剪前 global grad norm、裁剪后状态和实际 LR，确认 1k--3k hold 期间没有长期依赖
`grad clip=1.0`。

4. 在新单卡合同内验证连续运行与保存/恢复的一致性，并审计 optimizer、scheduler、EMA、RNG、
   数据游标和有限值；不要求与历史四卡轨迹 bit-exact。
5. 训练日志保留 FlowA、FlowB 和 CKA 项。`cka_weight=0` 时优化贡献明确为 0；若额外计算
   原始 CKA 诊断值，须使用独立字段且不参与反传，不能把诊断值和优化贡献混用。
6. LR 单元测试覆盖 `0/1000/3000/6000/8000` 连接点、两段 cosine 的单调性和 final LR=0；
   日志记录每次 optimizer update 使用的实际 LR，并记录裁剪前 global grad norm。
7. 不覆盖 Pg20 或其他 checkpoint；运行前确认卡空闲，采用独立日志和可恢复的长任务入口。

## 评价与解释

固定 step-0 Pg20 为产品基线，固定 A/P/H、seed、CFG、采样器和 VAE 比较过程 checkpoint。
评价重点是普通音区、平静段的质感和贴近感，以及活泼段的活力，同时检查高音、咬字、噪声、
长音频和音符保持是否退化。中途没有明显改善不自动推翻已确认的 8k 预算。

旋律评价以 P 音符骨架、REST/voiced 和边界为主；不把更接近非花丸源歌手的连续 F0、
颤音和局部起伏当成更好的分数。源歌手演唱细节不得作为新输入或奖励捷径。

该实验同时移除 CKA 并把 FlowB 权重从 2 提至 3，是联合改动；相对 source 的改善还包含额外
训练的影响。因此正结果支持修复路线，但不能单独证明 CKA 是根因；负结果也不能排除既往
CKA 长期训练的影响。只有需要进一步归因且另有预算时，才增加同起点同时间轴的 control 或
`NoCKA-1:2`，本轮不自动扩展这些分支。

新旧总 loss 不可直接横比；FlowB 更低或 CKA 优化贡献为 0 都不等于听感通过。首轮到 8k 后
完成 final audit 和听评，不自动延长训练。
