# CFG 质感对照（2026-09-25）

## 用户授权与问题

用户同意检查额外CFG是否贡献了质感缺口。只做两个片段的固定种子
推理对照，不训练、不改变编辑器或已有探针的默认参数。

当前探针非蒸馏，`cfg_strength=1,guidance_scale=1` 实际速度为
`2*v_full-v_drop_all`。待检验的问题是：额外差值项是否带来了
用户不喜欢的刺、哑，而非已经认定无条件分支有问题。
原唱VAE后处理方案不在本次实验范围内。

## 预先固定的方案

- 两段为既有团子（R03_06，seed102783）与月兔
  （R08_03/05，seed800383），不按新结果选种子。
- PgO8k EMA、285k VAE、原唱H/GAME-P、训练式A/B切分、
  固定A后验seed1042、32步Euler、t_shift=.5，全部不变。
- 始终 `cfg_strength=1`，三种 `guidance_scale=1,0,.5`；
  三者走相同的双分支batch计算路径。scale0仍保留完整A/H/P条件，
  只是额外差值系数为0，不是无条件生成。
- 每组三条生成，另加一条原轨参照，合计八条盲听。
- 原轨B不进入生成器条件；VAE往返另存，但不加入本次试听。
- 新生成scale1不被旧归档音频替代；另外记录新旧baseline差异。
- 保存完整上下文，所有候选常数增益至相同RMS，无EQ/压缩/降噪。
- 不用SIG挑选候选；GAME仅作音高/voiced状态辅助检查，不能替代听感。

## 听评与停止规则

主要看是否更接近目标发声质地，同时歌词、音准、可懂度没有明显退化。
不能把更糊、更弱、更气声自动解释为质感改善，也不以SIG上涨代替用户判断。
同档、难以区分允许明确记录，不强求微小排序。

若较弱CFG改善且没有明显退化，支持额外引导有贡献，不证明根因
必然在无条件分支或其训练量。
若不改善，只说明这个小范围修改未解决问题，不据此排除全部
推理误差或直接定位为模型能力不足。两段完成后不自动扩大参数扫描。

- 月兔：原轨 >> 0.5 >= 0≈1。

两组强偏好都对应原轨；削弱或取消额外CFG，没有在本次条件下
消除主要质感差距。0.5在月兔有弱优势，团子与1同档，不足以
宣布“半强度解决问题”或修改部署默认值。
完全取消额外CFG没有成为用户最佳生成；月兔的GAME辅助音高分数
亦下降，但用户没有单独报告跑调或咬字，不将自动指标当成听到
某种具体瑕疵的证据。

这一结果限制“主要缺口来自当前额外CFG”的简单解释，但不能证明
所有CFG、时间段引导或采样器均无关，也不能单独定位为训练欠拟合。
