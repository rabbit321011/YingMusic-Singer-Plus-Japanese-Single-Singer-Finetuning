# 用户听评标注汇总

整理日期：2026-09-26。

范围：本轮 PgO 质感诊断及相关盲听（记录日期 2026-09-23 至 25），不是整个项目历年的全部听评。来源为本任务用户消息、已存原始反馈 JSON 与诊断文档。保留原始观察，不重新拟合评分器、不修改旧标注。

## 清点结果

- 具名盲听共 20 组：A–F 一组、X 一组、Q 一组、V 一组、D 一组、G 五组、R 八组、K 两组。
- 这些组共呈现 117 个试听编号位置，包含原唱、重建和暗重复；不是 117 条独立标注或独立音频。Q1/Q5 未获单独描述。
- 另有两段 oracle 中途注入的定性反馈、旧 E/X4 复听、R03 揭晓后复听。
- G 之后的两批 R01–R04、R05–R08 均有独立原始 JSON。随后还有 K01/K02 对照。
- R09–R12 已制作音频，但在本轮检索的文档、反馈文件及本任务用户消息中未找到人工标注，不计为已听评。
- `=` 用户明确表示约等于；`>=` 保留原符号，旧分析将其作为弱偏好；`>>` 不擅自换成数值分差。
- 以下日期沿用实验记录日期，不假定为每条消息的精确发送时间。
