# M600-D 正式 30k 续训执行记录

## 裁决与目标

2026-08-04 同 step 盲听完成后解盲：12k 的 Model C 为 M600-D，Model D 为 HighLR。
用户主观判断 C 比 D 好一点。该结果满足“12k 明确领先才讨论 30k”的方向门禁，但优势较小，
因此本轮只把已通过工程门禁的 M600-D 继续训练到冻结 schedule 的绝对 step 30,000，不改结构、
数据或优化合同，也不据此直接启动 M600-B 或 1.5B。

interval DCP 和 30k final DCP，按每份约 11.55GB 估算新增约 208GB，磁盘门禁通过。

前 12k 实测平均约 3.054s/update；剩余 18k 训练约 15.27h，另加 18 次 checkpoint 保存约

合同的明确工程 bug 做最小修复并从最新已验证 checkpoint 精确恢复。模型结构、数据、loss、LR、
seed、batch、FSDP、no_sync、activation checkpoint 或精度的改变必须重新征得用户同意。

### 同 step 最终训练 Loss

HighLR 使用正式日志中的同一 Loss 公式 `FlowA + 2*FlowB + 0.7*CKA`；M600-D 使用每 10 step
日志，HighLR 使用每 50 step 日志，在相同 30k 终点分别对窗口均值比较：

| 窗口 | HighLR Loss | M600-D Loss | M600-D 相对降低 |
|---|---:|---:|---:|
| last-50 | 2.107400 | 2.083804 | 1.120% |
| last-500 | 2.092154 | 2.083648 | 0.407% |
| last-1000 | 2.086667 | 2.079073 | 0.364% |
| last-2000 | 2.086304 | 2.075696 | 0.508% |

last-1000 分项：HighLR/M600-D 的 FlowA=`0.298255/0.295230`，FlowB=
`0.862025/0.859974`，CKA=`0.091945/0.091279`。M600-D 的训练 Loss 优势稳定为正但很小，且
小于 12k last-1000 的 0.867% 优势；最终结果不支持“规模增加后收敛差距持续扩大”。

以上只比较训练 Loss。HighLR 的正式 paired Eval Loss 为 `2.0841`；现有 M600-D eval/audio
入口只授权 6k/12k checkpoint，且不是已经验证的 30k paired-loss 入口，因此本次没有拿训练
Loss 冒充 Eval Loss。M600-D 30k paired Eval 明确标记为待做。
