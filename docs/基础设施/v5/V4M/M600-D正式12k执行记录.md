## 自动监督

Codex 自动化 `维护 V4M M600-D 正式 12k`（ID `v4m-m600-d-12k`）是绑定当前聊天的每小时
heartbeat，由当前聊天的 Sol 模型执行检查，不创建独立任务：

- tmux session Loss/FlowA/FlowB/CKA、mean seconds/step 和 ETA；
- Traceback、NaN/Inf、OOM、NCCL、checkpoint 写入错误；
- GPU set 显存、利用率和 3GiB 最小余量；
- 最新 checkpoint 与磁盘剩余。

全部健康时自动化静默结束，不输出状态、不修改文件或进程。发现真实的代码、checkpoint、精确
恢复、监控或启动器 bug 时，允许保留现场、修复、最小验证并从最近已验证 checkpoint 按同一冻结
合同恢复；若修复需要改变实验语义或属于硬件/资源故障，则只报告阻塞。禁止自行切换 activation
checkpoint、sync_each、BF16、FSDP 拓扑、模型、数据、loss、LR、seed 或 batch。成功到达 12k并
核验 final/report 后暂停自身。
