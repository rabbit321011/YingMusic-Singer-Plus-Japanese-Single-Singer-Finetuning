# 1.5B 函数保持扩模设计

## 研究问题

验证能否把已经学到可用日语歌声分布、旋律控制和当前 P/H/INS 条件的 V4 checkpoint 扩展为
约 1.5B 参数的稠密 DiT，并在扩模转换时保留来源模型的生成函数，再利用新增容量继续训练。

本实验不回答“随机 1.5B 是否能从现有数据学会唱歌”。V4vf 已经提供反例证据：约 338M 的
随机 DiT 即使 loss 和 FlowB 可收敛，30k 与后续 VAE 适配的实际试听仍有大量噪音，未学到可用
歌声分布。因此 V4M 的第一门禁不是训练 loss，而是扩模前后的函数与听感连续性。

## 不可退让的约束

1. 来源必须是用户最终裁决可用、完整审计且冻结 SHA256: redacted
   V4IjPH v2 final；在它完成并听评前不冻结来源。
2. raw model 和 EMA 分别继承来源 raw/EMA；P embedding、H/PUL、INS adapter、词表和所有输入输出
   契约不变。
3. 扩模后的新增参数在 transition 时不得显著改变来源输出。随机新增层只能通过零门控、恒等映射
   或其他可证明的函数保持结构接入。
4. 来源与 transition 构建在 CPU/FP32 完成。BF16 只用于通过门禁后的训练计算，不覆盖来源资产。
5. 正式 1.5B 训练不能沿用当前每卡完整复制模型、EMA、梯度和 AdamW 的手动同步实现，必须使用
   经验证的参数/梯度/optimizer 分片方案。

## 当前架构审计

当前配置为：

```text
dim=1024
depth=22
heads=16
dim_head=64
ff_mult=2
long_skip_connection=True
```

checkpoint 的 DiT 参数统计：

| 组成 | 参数量 |
|---|---:|
| 22 个 DiT block | 323,254,272 |
| 文本、输入、时间、long skip 与输出组件 | 14,864,608 |
| DiT 合计 | 338,118,880 |

单个 block 的参数公式为：

```text
P_block(d) = 14d^2 + 13d
```

非 block 组件在保持现有文本、MIDI 和 latent 接口时为：

```text
P_other(d) = 8.875d^2 + 1095d + 4,437,184
```

## 宽深候选

下列标准稠密 DiT 都接近 1.5B：

| dim | depth | heads | 参数量 | 主要问题 |
|---:|---:|---:|---:|---|
| 1024 | 101 | 16 | 约 1.499B | 要新增 79 个串行 block，训练、推理和分片通信过深 |
| 1536 | 45 | 24 | 约 1.514B | 宽度为 1.5 倍，通道和 head 复制不均匀，层数仍翻倍 |
| 1792 | 33 | 28 | 约 1.519B | 宽度为 1.75 倍，迁移映射与审计更复杂 |
| 2048 | 25 | 32 | 1,512,576,192 | 单 block 激活更宽，但迁移最规则，只新增 3 层 |

当前推荐 `2048 x 25`。该选择不是质量最优的数学定理，其优势是 checkpoint 迁移可验证、GPU
矩阵形状规整、FSDP all-gather 次数较少，并且目标参数量准确。若真实 45-60 秒显存 probe 否决
该宽度，允许回到 `1536 x 45` 比较；不得在没有同口径证据时宣称任一宽深比听感必胜。

## 函数保持宽化

### 基本映射

`1024 -> 2048` 使用成对复制。对旧隐藏通道 `x_i`：

```text
x_i -> [x_i, x_i]
```

消费重复输入的线性层将旧权重均分到两个输入副本；产生隐藏输出的线性层将旧输出复制到两个
输出通道。简单线性关系满足：

```text
(W / 2) x + (W / 2) x = W x
```

### 必须覆盖的模块

- input projection：输入维度不变，输出通道成对复制；
- convolutional position embedding：在每个 group 内成对复制通道，并按 fan-in 归一；
- time MLP：首层复制输出，次层对重复输入均分并复制输出；
- Attention：旧 16 heads 各复制为两个新 head，保持 `dim_head=64`；Q/K/V 与输出投影按重复
  fan-in/fan-out 转换，RoPE 定义不变；
- FFN：旧 1024/2048 通道分别扩为 2048/4096，按相同规则复制；
- AdaLN：六个 modulation chunk 必须逐 chunk 复制，禁止把展平输出直接错误切半；
- long skip：分别处理当前 hidden 与 residual 两个 2048 维输入区域；
- final AdaLN：两个 modulation chunk 逐 chunk 复制；
- output projection：将成对隐藏通道平均回原 64 维输出；
- text encoder 的 512 维内部组件、MIDI 128 维投影、VAE latent 64 维接口保持不变并精确复制。

在 dropout 关闭的 FP32 eval 中，成对复制保持 LayerNorm 的均值和方差；Attention 的重复 head
产生相同输出，输出投影求平均后恢复旧结果。实现必须用逐模块测试证明，不能只凭总体 loss 接近。

## 三个新增 block

25 层中的 22 层从来源 22 层逐一宽化，另外三个 block 均匀插入网络。新增 block 使用当前 DiT
已有的 AdaLN-zero 机制：attention 和 FFN gate 初始为零，因此初始满足：

```text
new_block(x) = x
```

建议的初始位置是在来源第 7、14、21 个 block 之后。位置不是冻结常量；转换器必须在 manifest
中记录来源层到目标层的完整映射，且新增层在 FP32 eval 中通过逐层恒等性测试。

## 对称性与新增容量

完全相同的通道副本可能持续接收相同梯度，无法形成新容量。正确顺序为：

1. 先构建无扰动的函数保持模型；
2. 对 raw 和 EMA 完成逐模块及端到端等价性审计；
3. 再对可训练 raw model 的重复对加入极小、确定性、反对称扰动 `+epsilon/-epsilon`；
4. 扰动后的端到端 latent 与固定样本听感必须再次通过门禁；
5. EMA transition 的处理策略必须单独冻结，不默认向发布 EMA 注入未经验证的扰动。

`epsilon` 不在设计阶段凭经验冻结，应通过输出相对误差、固定推理和短期梯度差异共同确定。

## Checkpoint 转换策略

transition checkpoint 必须包含：

- 来源 checkpoint 绝对路径、schema、global step 和 SHA256: redacted
- 来源 raw/EMA 到目标 raw/EMA 的逐 tensor 映射 manifest；
- 目标架构配置和精确参数统计；
- 新增层初始化、破对称 seed 与 epsilon；
- P/H/INS 及非 DiT 状态的继承策略；
- 转换代码、配置和依赖文件 SHA256: redacted
- FP32 等价性审计结果；
- 明确声明 optimizer/scheduler transition policy。

推荐分别宽化来源 raw model 与来源 EMA，不用 EMA 覆盖 raw。模型能力由当前 checkpoint 继承，
但由于参数 shape 和新增自由度改变，首版不迁移 AdamW moments；optimizer 与 scheduler 重新建立，
使用独立 warmup。该策略必须作为架构 transition 记录，不能宣称 bit-exact 延续旧 optimizer。

## 四卡训练内存设计

1.5B 不能使用当前每卡完整复制训练状态的实现。首选：

```text
FSDP FULL_SHARD
BF16 parameter/reduce mixed precision
FP32 master weight 与 FP32 AdamW state
逐 DiT block activation checkpointing
EMA 按 rank 分片更新与保存
VAE latent 离线预计算或等价的 VAE GPU 移除方案
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
分片、可审计、可合并的 checkpoint
```

EMA 不采用每步把完整 1.5B 权重搬到 CPU 的方案，避免持续 PCIe 传输；优先保持与 FSDP 参数一致
的分片 EMA，推理发布时离线合并。当前训练目标直接调用 `raw_model.transformer` 并手动同步梯度，
新入口必须确保实际 forward 经过 FSDP wrapper 的参数 all-gather 生命周期，不能只把旧入口外包一层。

当前 338M 单卡审计表明：默认 allocator 的真实 allocated 峰值约 15.72GiB、reserved 峰值约
20.20GiB；`expandable_segments:True` 将同口径 reserved 降至约 16.93GiB。该结果只证明 allocator
策略有效，不证明 1.5B 或 60 秒序列可运行。正式资源判断必须使用扩模后的真实入口复测。

## 强制门禁

### 静态转换门禁

- 来源 checkpoint SHA256: redacted
- 每个来源 DiT tensor 恰好映射一次，无静默 missing/unexpected key；
- 目标 raw、EMA 和非 DiT 状态全部有限；
- 参数量与 `1,512,576,192` 的目标审计一致；
- 新增 block 在无扰动 FP32 eval 中为恒等映射；
- tokenizer、P/H/INS、latent 和输出 shape 与来源完全一致。

### 函数门禁

- 对固定随机 latent、真实 batch、多个 timestep 和所有 CFG/drop 条件比较来源与扩模输出；
- 分别审计 raw 与 EMA，不用总体平均掩盖单支偏差；
- 保存逐模块 max-abs、RMSE、相对误差和最终 velocity 误差；
- 无扰动模型达到数值等价后，再对破对称模型设置单独容差；容差由实际 FP32 基线校准，不在实现前
  随意写死；
- 固定推理集完成扩模前后盲听。出现噪音、静音、旋律或咬字明显退化时禁止进入训练。

### 训练工程门禁

- CPU 构建与 checkpoint round-trip；
- 单卡 BF16 forward/backward/update，记录每阶段 allocated/reserved；
- 30 秒和 45-60 秒分别做 `grad_accum` 同口径 probe；
- 四卡 FSDP 10-step smoke，确认所有 shard 更新、loss 有限且无 rank 漂移；
- 连续 10 与 5+resume5 比较 model、EMA、optimizer、scheduler、rank RNG 和数据游标；
- checkpoint 分片完整性、离线合并和真实推理通过；
- GPU 峰值必须保留明确安全余量，不以单次恰好未 OOM 作为正式通过。

## 训练阶段与停止条件

训练阶段当前只冻结原则，不冻结具体步数和 LR：

1. transition 后先做容量唤醒，新层和新增自由度可使用独立参数组，继承子空间使用更低 LR；
2. 固定样本确认未遗忘后再进入全模型联合训练；
3. 每个阶段保留来源 checkpoint 同输入对照，FlowB 只作为训练健康指标，不替代听感；
4. 若扩模后零步听感已退化，停止并修复转换，不允许靠长训掩盖错误；
5. 若短期训练出现来源能力快速遗忘，停止并调整参数组、warmup 或稳定约束；
6. 若四卡在 30 秒或 60 秒门禁中没有可接受的显存余量，重新裁决宽深比或数据长度，不静默裁剪。
