# 发声区噪音诊断

本分支定位 SVS 结果在头戴耳机下随发声出现的颗粒、砂噪或雪花质感。

## 边界

- 不把症状描述为静音段底噪或全段雾感；
- 先区分 DiT/CFG、ODE 数值积分、VAE decoder 与 PCM 导出削波；
- 固定 checkpoint、输入、H/PUL、GAME、seed 与 VAE，只做单变量推理消融；
- 人工结论使用等 RMS 试听，避免响度偏差。

## 阅读顺序

先读 `发声区生成纹理诊断.md` 了解症状和既有因果消融；需要选择自动评分器时，再读 `噪音评分器十档听评.md` 并按其十档听评口径裁决；决定是否把 UTMOS22 接入相对奖励训练时，最后读 `UTMOS22多种子极差与GRPO可行性.md`。
