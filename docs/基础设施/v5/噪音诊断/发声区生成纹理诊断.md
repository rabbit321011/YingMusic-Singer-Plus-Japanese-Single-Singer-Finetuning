# 推理链审计

当前 `Singer.sample()` 使用：

```text
Euler ODE
32 steps
t_shift = 0.5
v = pred + (pred - pred_drop_all_cond) * cfg_strength
```

因此本实现的 `cfg=1` 已经做一次额外条件残差外推，不是无引导；conditioned-only 由 `cfg_strength < 1e-5` 分支实现，即入口 `cfg=0`。

训练侧 audio/text/midi dropout 独立采样为 `0.3 / 0.15 / 0.3`，三者同时丢弃的联合概率只有 1.35%。推理却固定使用 full-condition 与 drop-all-condition 的差做外推。该联合无条件分支样本较稀少，是 CFG 放大生成纹理的合理嫌疑，但尚不能仅凭概率声明根因。

# 首轮等响听评与波形定位

用户使用头戴耳机完成首轮等响听评：

- V4IPH CFG 1 的噪音略重于 CFG 0，但 CFG 0 仍有不少噪音；
- V4IPH CFG 0 的咬字明显更差、声音轻微发虚；2--4 秒噪音略少，17--19 秒咬字退化明显；
- V4PH CFG 1 噪音更重，CFG 0 则出现雾感且咬字不如 CFG 1；
- Euler32、Euler64、Midpoint32 听感约等；
- 噪音被描述为毛刺、破音边缘、不自然的哑嗓沙声，波形观感近似方波边缘，而非稳定的正常沙声。

对应时间段的周期分析与听感一致：

- V4IPH 2--4 秒，CFG 1 的 4--12 kHz 能量比 CFG 0 高约 3.9 dB，周期相关性为 `0.9339`，低于 CFG 0 的 `0.9535`；
- V4IPH 17--19 秒，CFG 1/0 的谐波对非谐波比均接近 0 dB；CFG 0 周期相关性进一步降到 `0.8818`，CFG 1 为 `0.9017`，而 V4PH/V4fg 约为 `0.95`；
- 所以 CFG 0 在前段减少高频毛边，却没有修复后段声带周期不稳，并牺牲了歌词条件强度。

# 中间 CFG 盲听结论

用户在不知道映射的情况下完成 V4PH/V4IPH 各五档等响盲听：

- 两模型的噪音与咬字均为“都差不多”，实际差别小于听评误差；
- 无法选出最佳折中；
- V4PH C 单独被备注为可能发虚、整个声音飘起；揭盲后 C 为 CFG 0.25。

因此 latent 尾部虽随 CFG 单调变化，但 `0.25/0.5/0.75` 没有形成可重复的感知收益。结合 CFG 0 已确认的咬字/实体感损失，标量 CFG 调参不能修复本问题；保留 CFG 1 作为现有控制基线，停止 CFG 与 solver 消融。

# H/Hg/P 跨路线隔离

对 CFG 1 全部 27 组追加 V4H/V4Hg 对照：

| 模型 | VAE | 8--20 kHz 谱平坦度中位 | 12--20 kHz 谱平坦度中位 |
|---|---|---:|---:|
| V4fg 10k | 285k | 0.00287 | 0.00162 |
| V4H 30k | official | 0.00590 | 0.00857 |
| V4Hg 10k | 285k | 0.00288 | 0.00170 |
| V4PH 30k | official | 0.00582 | 0.00926 |
| V4IPH 30k | official | 0.00513 | 0.01157 |

V4H 与 V4PH 使用 official VAE，宽带纹理相近，说明 GAME-P 不是主因。V4Hg 从 V4H 出发切换 285k latent 域并适配 10k 后，12--20 kHz 谱平坦度 27/27 下降到接近 V4fg；V4IPH 无 A 又在 official 路线上进一步增加高频能量/空气带纹理。

该结果与纯 VAE 重建并不矛盾：official VAE 对真实 latent 的重建可以正常，问题可能只在 DiT 生成 latent 与 decoder 域的交互。已生成 `cross_model_equal_rms_blind_ayo/` 复核 H/Hg/PH/fg 的感知排序；仍需同时听 official/285k 纯重建，才能把 VAE 本体与生成 latent 域错配分开。

# V4IPH 独立工程审计

考虑 V4IPH 由独立 agent 实现，重新按“实现可能有错”审计，而不引用原实现者自证作为结论。

实际 final checkpoint 与 runtime 复核结果：

- checkpoint 为 complete 30k，推理严格加载 EMA；schema、training/contract/renderer/config、official VAE、GAME manifest/model 哈希全部匹配；
- 训练 `cond=zeros(1,T,64)` 与推理 `cond=zeros(1,1,64), lens=0` 展开后逐值相同；
- learned P embedding 经 `Singer.sample()` 的等长 SOME transport 后逐值相同；
- 训练/推理 input embedding 最大差为 0，零 cond 下 drop-audio 与不 drop 的最大差为 0；
- packed CFG 相对分开 forward 的 conditional/drop-all 最大差为 `5.64e-4/1.67e-5`，属于批计算浮点差，且所有同源模型共用该路径；
- 随机抽取一条真实训练音频，按 manifest 原 seed 重新运行 GAME；durations、presence、scores、257/128 维 posterior、classes、duration frames 与 valid 共 8 组数组全部 bit-exact；
- contract 5 项、placement 3 项测试全部通过，训练/runtime/推理脚本静态编译通过。

训练没有人工尾静音而正式推理追加 1 秒尾静音，是确实存在的通用训练/推理差异。单独取消尾静音后，V4IPH latent `std/deltaStd` 从 `1.1644/1.4304` 变为 `1.1749/1.4395`，没有修复过冲；2--4 秒与 17--19 秒高频略降但不足以解释整体现象，因此不构成 V4IPH 特有根因。

独立审计结论：**未发现能够解释当前噪音的 V4IPH 特有工程错误；高置信归类为方案/训练域问题。** 无 A 使全段依靠内部身份与 text/MIDI 条件生成，在 official latent 域已有生成纹理的基础上进一步损失周期稳定性。该结论不等于逻辑证明不存在任何未知 bug，但已覆盖最可能的权重、VAE、cond、text、MIDI_P、GAME、renderer、CFG、时间轴与裁切路径。

# PH 到 IPH 的感知裁决

用户进一步明确：本轮模型间最显著的听感跳变是 `V4PH -> V4IPH`，不是 V4PH 内部不同 CFG/solver 的细小差异。全量客观统计支持该方向：CFG 1 下 PH 到 IPH 的 RMS 中位增加约 `1.44 dB`，8--20 kHz 能量比增加约 `2.57 dB`；同一 `source singer` 的生成 latent `maxAbs` 从 `5.60` 升到 `6.01`，时间差分 std 从 `1.4026` 升到 `1.4304`。

因此最终归因分两层：official VAE latent 域解释 V4H/V4PH 已共有的宽带生成纹理；取消 A 则解释 PH 到 IPH 的额外明显退化。V4IPH 应记录为“工程实现通过、无 A 感知假设未通过”的负结果，而不是与 V4PH 基本等价的可选分支。
