# 长音频训练实验

## 目标

验证在保持现有短样本训练分布的同时，加入 45-60 秒长样本，是否能降低长程生成中的局部噪音、
电音、雪花声和约 20 秒附近的声学崩坏，并提高后段文本、旋律和声学状态的持续稳定性。

T1 已证明句级锚点能明显改善长、多句文本命中，但不能解决约 20 秒附近的声学故障。
V4L 不把文本锚点修复与长程声学稳定性混为同一问题。

## L 的精确定义

```text
同一 BV、同一 split 的连续合格短段
  -> 按 seg 编号顺序拼接为 45-60 秒 WAV
  -> Whisper 对合并 WAV 重新整段转写
  -> 与旧段歌词拼接结果做自动一致性门禁
  -> SOFA 对新整段重新对齐
  -> token、时间戳和音频自动门禁
  -> V4L 长样本池
```

首轮不从原始整段 WAV 自由重切，也不改变旧切分脚本的 `MAX_SEG`。原因是自由重切会改变边界、
过滤范围和文本标签，扩大实验变量。首轮只使用已经通过现有过滤的 waveform 内容。

## 数据合并规则

候选短段必须同时满足：

1. 属于同一个 BV 和同一个 train split；
2. 文件名可解析为相同 basename 下的连续 `segNNN`；
3. 每段均存在于冻结的 token-safe 训练清单；
4. 采样率、声道、位深和文件可解码性一致；
5. 不跨缺号、过滤段、test 段或来源边界；
6. 合并总时长进入 45-60 秒目标窗口。

首轮使用非重叠窗口，避免少数长源通过滑窗被过度重复。窗口不足 45 秒不进入长样本池；超过
60 秒时在最近的完整短段边界结束，不裁断短段。若后续需要滑窗或 60 秒以上窗口，作为独立变量记录。

拼接不使用 crossfade、响度重整或额外静音。输出总帧数必须等于输入段帧数之和，原段顺序和
SHA256: redacted

## Whisper 自动门禁

合并后重新运行冻结版本和参数的 Whisper。旧段 `Text`/kana 按顺序拼接，作为自动校验基准，
但不直接充当新的时间戳。

至少检查：

- 新旧 kana 的编辑距离或相似度；
- 是否出现整句缺失、重复或新增幻觉；
- 文本长度比例是否异常；
- 语言是否仍为日语；
- 重复运行是否确定。

阈值在首轮统计新旧分布后冻结。未通过一致性门禁的样本自动排除，不进入人工审核。

## SOFA 与 token 门禁

通过 Whisper 门禁后，对合并 WAV 和新整段文本重新运行现有 SOFA 正式通路。要求：

- Phrase 起点单调且位于音频范围内；
- Phrase 不重叠、不越界，末句与音频尾部关系合理；
- 合并边界附近不存在系统性对齐跳变；
- token placement 不溢出帧范围；
- tokenizer、词表和 SOFA 模型版本与现有正式数据一致。

任一门禁失败即自动排除。旧短段 SOFA 仅用于诊断新对齐是否发生异常偏移，不直接拼接成正式
V4L 标注。

## 训练对照

V4L 首轮必须保留短样本并新增长样本池。正式训练前冻结：

- Control 使用的 checkpoint 或初始化来源；
- VAE、MIDI 表示、A/B 构造、T1 和 CFG/dropout；
- 短长采样比例、有效 batch、LR、schedule、步数和 seed；
- 每个 checkpoint 的固定短/长生成集。

唯一主变量应为长样本参与训练。首轮短长采样比例在数据统计和显存 smoke 后确定，不在文档阶段
凭经验硬定。Control 与 V4L 必须按相同更新步数比较，同时记录见过的音频秒数，避免长样本因
单 step 信息量更大而形成隐式训练预算差异。

## 工程门禁

正式训练前依次完成：

1. 小规模 manifest dry-run；
2. 10 条长样本的拼接、Whisper、SOFA 和 token 全链路；
3. 单卡 forward/backward 显存与耗时探针；
4. DDP 10-step smoke；
5. checkpoint round-trip 和固定长样本真实推理。

长序列会提高 attention 和中间激活成本。smoke 必须记录峰值显存、step time、有效音频秒数、
OOM 情况和预计训练时长，再决定使用的卡数、梯度累积与短长采样比例。

服务器长任务使用 tmux session ETA。

## 评价

至少分开记录：

- 文本：整段 PER、逐句命中和后段漏句；
- 旋律：F0-CORR、voicing、音符起止和后段漂移；
- 长程声学：20 秒前后分段统计噪音、电音、雪花声和局部崩坏；
- 身份与唱法：target singer、轻柔、强弱、颤音和滑音是否保持；
- 短样本回归：原固定短集不能因加入 L 明显退化；
- 效率：峰值显存、step time、总训练时长和推理稳定性。

PER 或 loss 单独改善不能判定 V4L 通过。长音频人耳稳定性改善且短样本无明显回归，才允许扩大训练。

## 停止条件

- 自动合并无法保证同 BV、连续编号或 train/test 隔离；
- Whisper 新旧歌词一致性大面积失败；
- SOFA 在长样本上出现系统性错位、越界或 token overflow；
- 45-60 秒训练无法在可接受的显存和吞吐下运行；
- 长样本 loss 改善但固定长生成集无稳定收益；
- 长程稳定性改善但短样本文本、旋律或美学明显退化；
- 为维持训练而同时改变多个模型或数据变量，失去单变量解释。
