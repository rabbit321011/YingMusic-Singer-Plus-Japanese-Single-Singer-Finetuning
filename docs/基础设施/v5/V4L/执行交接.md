## 下一步

恢复工作时按以下顺序：

1. 先读 `main_V4L.md`、`长音频训练实验.md` 和本文；
2. 确认 V4IjPH 任务与 GPU 所有权，不抢占其资源；
3. 由用户冻结 V4L 的正式模型基线和短长比例；
4. 为该基线建立独立训练入口，不修改其他分支权威文件；
5. 做 DDP 10-step smoke，记录每卡显存、step time、短长 batch 次序和 loss；
6. 做连续 10 与 5+resume5 的数据游标/状态一致性门禁；
7. 门禁全部通过后仍需用户明确授权，才可启动正式训练。

禁止事项：

- 不因单卡 probe 成功自动启动训练；
- 不把自然 9.7447% 写成正式采样比例；
- 不复用 probe 进程状态或不存在的 checkpoint；
- 不修改或 resume V4IjPH；
- 不把显存可行性写成质量收益。
