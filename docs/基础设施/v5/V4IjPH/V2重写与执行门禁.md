# V2 重写与执行门禁

## 1. v1 否决结论

2026-08-01 接管审计发现 v1 已越过文档门禁启动四卡正式 30k。该轮在约 step 1250 主动停止，
没有写出正式 checkpoint，cache v1、step-10 smoke checkpoint 和日志保留。

v1 不允许继续使用，原因包括：

1. step-8000 gate 将 GPU 当前 state 与 `map_location=cpu` 的参考 state 直接交给
   `torch.equal`，在服务器相同 PyTorch 环境必然抛出 device mismatch；
2. 10-step smoke 位于 adapter 冻结区，只验证了 V4IPH 全零 cond，没有覆盖 INS forward、
   backward、DDP、optimizer、EMA 或 resume；
3. cache record 没有保存实际 VAE 输入波形的 SHA，独立 auditor 只比较 `SampleId` 集合；
4. adapter weight decay/Adam betas 与推理入口尚未冻结便直接启动正式训练；
5. checkpoint auditor 不核对 adapter 的实际 Adam step、LR 或精确 EMA step。

v1 本地源码归档于：

```text
experiments/v4ijph_v1_rejected_20260801/
```

该目录只作证据，禁止上传覆盖 v2 入口。

## 2. v2 transition

v2 不再从 P500 重放前 8k。起点固定为正式 V4IPH step 8000 周期 checkpoint：

```text
schema: v4iph_training_checkpoint_v1
global_step: 8000
run_state: running
SHA256: redacted
```

必须完整继承以下 section：

- raw DiT/P/H state；
- DiT EMA state、step 与 initted；
- DiT optimizer、scheduler 与 LR；
- 四 rank Python/NumPy/CPU/CUDA RNG；
- sampler epoch、batch offset 与 running metrics；
- P support counts、P500 transition audit 与初始 P；
- H/PUL embedding audit。

adapter 使用独立 RNG 初始化，不改变继承 RNG。global step 8001 是第一个 INS adapter update。
因此 v2 只执行 22,000 次新 optimizer update，但 checkpoint 的全局步数仍为 8,001..30,000，
与 V4IPH 同步 checkpoint 可直接比较。

## 3. cache v2

schema 冻结为：

```text
v4ijph_ins_cache_v2
```

每条 record 必须绑定：

- manifest `SampleId` 与原始 `Path`；
- 实际解析绝对路径；
- 44.1kHz 单声道、最多 30 秒截断后的 float32 样本数；
- 上述实际 VAE 输入波形的 SHA256: redacted
- cache row 与 FP16 INS row。

cache 同时保存 ParaSpeechCLAP source、WavLM、Granite 和 Intrinsic checkpoint 四份 inventory
指纹。构建时逐文件复核 inventory；独立正式 audit 重新读取全量训练音频，逐条复算波形 SHA。
任何 status 非 1 的行在续跑时重试，不再永久卡在 failed 状态。

## 4. adapter 与优化器

```text
architecture: 768 -> 512 -> SiLU -> 256 -> SiLU -> 64
output projection: weight/bias exact zero initialization
INS dropout: 0.3
AdamW betas: (0.9, 0.95)
weight decay: 0.01
EMA beta: 0.995
EMA update_after adapter step: 100
EMA update_every: 1
```

LR 按 global update 冻结：

```text
8001..14000:  linear 0 -> 1e-4
14000..18000: cosine 1e-4 -> 1e-5
18000..30000: cosine 1e-5 -> 0
```

checkpoint schema 为 `v4ijph_training_checkpoint_v2`。auditor 必须核对 adapter 六个 Adam state
的 step 均等于 `global_step - 8000`，当前 LR 等于纯函数 schedule，adapter EMA step 也等于该值。

## 5. 推理契约

入口：

```text
package_v4c_finetune/infer/v4ijph_sampling.py
```

R 必须是用户明确选择的完整单声道target singer片段，不做时长裁剪。provenance 保存源文件 SHA、原采样率、
重采样后样本数/时长和 encoder 输入波形 SHA。

`style_cond [1,T,64]` 覆盖完整生成时间轴；`ref_len=0`，R 不进入 VAE、不产生 prompt mask、
不清零任何 GAME MIDI 帧。CFG 的 conditional 和 content-unconditional 两支都保留相同 style，
只对歌词/MIDI 内容差执行原有 guidance，因此 style guidance 固定为 1。null INS 时 style 全零，
退化为 V4IPH 的无 A 条件。

## 6. 强制执行顺序

1. 本地 py_compile、ruff、v2 单测与 V4IPH/H 回归；
2. 服务器 py_compile、bash `-n` 和同一组单测；
3. cache v2 train/eval 全量构建；
4. inventory + 全量 waveform rehash 独立 audit；
5. 单卡真实两 update probe：update 1 末层梯度，update 2 前两层梯度；
6. 四卡 active adapter 8001..8010 smoke；
7. 8010 checkpoint 独立 audit；
8. 四卡连续 10 与 5+resume5 全 section bit-exact；
9. 使用采样入口验证同 R determinism、null INS、不同 R style cond 和 provenance；
10. 用户明确授权后才允许从 V4IPH step 8000 启动正式 v2。

任一门禁失败均停止，不允许用训练 loss 正常替代工程证据。
