## 7. Minimal Stage B Experiment

The first experiment should answer one narrow question:

> Given fixed latents from the existing encoder, can a decoder adapted on a tiny target singer set improve unseen target singer reconstruction?

It must not be a one-file memorization demonstration.

### Data

Use clean normal singing only. Split by source song/video before cutting segments:

- tiny train: 3–5 distinct source songs;
- validation: 2 entirely unseen source songs;
- listening test: at least 3 held-out segments, including the existing sample02–04 when their source is not in train;
- exclude noisy speech-like, accompaniment leakage, clipping, and obvious live-stream contamination where possible.

### Fixed interface

- freeze encoder;
- cache fixed sampled latents with seed and cache posterior means separately;
- train decoder only;
- keep 64-channel, 21.533 Hz interface;
- preserve stereo and -6 dBFS input normalization used by current inference;
- crop on 2048-sample boundaries.

### Stage B0: implementation smoke test

- one or two clean clips;
- 200–500 updates;
- 3–5 second crops;
- simple L1 waveform plus multi-resolution spectral loss;
- goal: prove checkpoint save/load, loss decrease, and output validity;
- not used for perceptual conclusions.

### Stage B1: tiny generalization probe

- 3–5 train sources, 2 unseen validation sources;
- fixed number of updates, likely 1k–3k;
- decoder-only;
- spectral reconstruction loss first;
- compare official decoder and adapted decoder on exactly the same cached held-out latents;
- blind listening is the primary decision.

Do not add GAN training in B1. GAN/discriminator integration substantially increases complexity and can add fake sharpness. Add it only if spectral-only adaptation improves blur but remains over-smoothed.

## 8. Evaluation

Three-way human comparison on held-out samples:

1. normalized original;
2. official VAE reconstruction;
3. adapted decoder reconstruction from the same latent.

Judge:

- target singer gentleness and beauty;
- naturalness;
- clarity without harsh artificial high-frequency texture;
- articulation edge and breath detail;
- bathroom/electronic/snow artifacts;
- source memorization or timbre exaggeration.

Automatic spectral losses are diagnostics only. They cannot decide whether the subtle target singer timbre is restored.

## 9. Stop Conditions

Stop decoder-only work if:

- train reconstruction improves but every held-out source is unchanged;
- held-out audio becomes sharper but less natural;
- the decoder memorizes source songs or injects a fixed coloration;
- improvements require changing the 64-channel latent distribution, which would invalidate current DiT outputs;
- posterior-mean-only improvement cannot transfer to latents generated by the Singer DiT.

Proceed to a broader decoder adaptation only if blind listening shows repeatable improvement on unseen sources without new artifacts.
