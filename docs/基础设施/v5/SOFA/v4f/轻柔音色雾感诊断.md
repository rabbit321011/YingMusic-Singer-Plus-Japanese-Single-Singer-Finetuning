# 轻柔音色雾感诊断

## 目标

判断 sample_15 的全段雾感是随 A 区参考、随 B 区轻柔唱法，还是由 285k VAE 本身产生。

## 对照

- 雾感样本：sample_15
- 正常对照：sample_14
- 模型：V4fg 10k
- VAE：285k online
- reference tail：0.5s，用于保持原观察条件
- T1、seed、steps、CFG 与正式 v2 一致

2×2：

```text
A15 + B15
A14 + B15
A15 + B14
A14 + B14
```

每个固定 B 的目录只匿名比较 A15/A14；正式 v2 中的 N 原始输出另存为 `formal_N_baseline.wav`。

## 随机性控制

复现实验时发现现有正式推理只在 DiT sampling 前设 seed，VAE posterior encode 发生在 seed 之前，因此独立重跑不保证逐采样复现。

本实验采用：

- A posterior 使用固定独立 seed；
- B posterior 使用另一固定独立 seed；
- 同一 A 跨两个 B 保持相同 latent；
- 同一 B 跨两个 A 保持相同 latent；
- 正式 v2 的 N 原始输出保留在包内作为原雾感基线。

## A/B 交换听感结果

揭盲映射：

```text
variant A = A14（正常参考）
variant B = A15（轻柔/雾感参考）
```

固定 B14（normal）：

- `formal_N_baseline`（A14+B14）：没有明显雾感，但相对 GT 失去轻柔感；
- variant A（A14+B14）：同样失去轻柔感，与 baseline 一致；
- variant B（A15+B14）：没有雾感，且略微轻柔，但仍明显不如 GT 轻柔。

固定 B15（soft）：

- `formal_N_baseline`（A15+B15）：有雾感，也不轻柔；
- variant A（A14+B15）：没有雾感，但也没有轻柔感；
- variant B（A15+B15）：有雾感，也不轻柔，与 baseline 一致。

## VAE 纯重建听感

A15、B15、A14、B14 四组 original/285k reconstruction 均正常：没有新增或明显加重雾感，也没有发现能够解释正式生成雾感的异常轻柔感损失。

因此排除 285k VAE 单独造成该问题，也没有证据指向源录音本身带雾。

## 最终判断

- A15 携带部分轻柔条件：换入 B14 后，生成结果略微变柔；
- A15 单独不足以产生雾感：A15+B14 没有雾感；
- B15 单独也不足以产生雾感：A14+B15 没有雾感；
- A15+B15 组合稳定复现雾感，同时没有保留目标轻柔感。

结合 VAE 纯重建全部正常，可确认当前雾感来自 DiT 生成阶段的条件交互：模型对 A15+B15 这类一致但罕见的轻柔 A/B 条件发生错误映射，将目标轻柔表现转换成雾感。它不是 A-only、B-only、285k VAE-only 或源录音自带的问题。

## 后续方向

当前只完成 sample_15/14 单案例定位，不能据此判断该问题在轻柔唱法中的普遍性。

进一步做多样本 DiT 条件交叉诊断，需要先建立可人工确认的唱法/音色样本池。`STYLE_EMBEDDING/` 已完成 92,695 个 SOFA 句级样本的七模型 embedding，并将 MERT layer1 冻结为当前工程表示；正式聚类、人工试听、语义命名和可发布样本池仍未完成。因此本诊断继续停在单案例结论，不直接启动下一轮推理消融，也不回到 VAE 分支。

该依赖只阻塞轻柔雾感的多样本外推，不是 V5 总路线的当前门禁。
