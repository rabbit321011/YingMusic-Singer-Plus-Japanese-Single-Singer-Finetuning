# v4f 子分支

本子分支从 V4f SOFA 重训开始，继续覆盖 V4g/V4fg 的 285k VAE 汇合实验、
T1 逐句推理、正式盲听选型和当前后续诊断。

## 当前结论

- SOFA + T1 已确认能修复长、多句文本控制，但不单独解决音质和长程声学稳定性。
- V4c/V4f/V4g/V4fg 共 14 个 checkpoint 的正式 T1 盲听已完成。
- **当前主候选：V4fg 10k + 285k online VAE。** 它在歌词稳定、自然度、情感和高表现力之间综合最佳。
- V4fg 轨迹显示 2k 生动但易崩、4k 略糊、10k 最佳、15k 高音开始轻微异常，10k 是当前甜点位。
- A→B 边界消融已完成：0s 对部分样本有明确收益，但不普适；0.25s 无独立优势，暂不改全局默认值。
- 轻柔音色 A/B 交换已完成：A15+B14 与 A14+B15 均不雾，A15+B15 稳定雾且不轻柔；四组 285k VAE 纯重建全部正常。
- 单案例已定位雾感产生于 DiT 生成阶段的 A15+B15 条件组合，不是 A-only、B-only、VAE-only 或源录音自带；是否属于普遍的轻柔唱法缺陷尚未确认。
- 轻柔雾感的多样本诊断仍等待 `STYLE_EMBEDDING/` 完成正式聚类、人工命名和样本池发布；该叶节点暂缓，不作为 V5 总路线门禁。
- 本子分支已经完成当前基线选型。27 组真实跨源 A/B、七 checkpoint 双 CFG 评测集已生成并通过完整性校验，人工评分进行中；评分完成后再据结果决定 X1、P1 或 P3。边界 0s 留待真实跨源工作流复核。
