## 实验含义

- T0：整个 B 区歌词只有一个起点。
- T1：每句歌词使用自己的句首时间戳。
- 两版使用相同 V4f 24k、相同旋律、相同参考音频、相同 seed42、相同 CFG 和推理步数。

## 试听顺序

1. 先听原参考音频，记住旋律和每句的位置。
2. 再听同组 T0/T1；正式盲听包会匿名为 A/B。
3. 重点听第二句以后和最后几句，不要只听开头。
4. 先独立记录文本、旋律、美学，再做综合选择。

## 评测标准

### 1. 文本

- 每句应该有的内容是否完整唱出。
- 是否从第二句开始漏句、乱句或唱成别的字。
- 是否把上一句或下一句的咬字串进来。
- 长音频后半段是否发生明显咬字崩坏。

填写：

```text
文本更好：A / B / 相同
```

### 2. 旋律

- 是否跟随原参考的音高走向。
- 起音、句间节奏和长音位置是否明显跑掉。
- 是否出现突然跑调、断裂或异常抖动。
- 是否存在“为了把字唱全而把旋律硬拽坏”的情况。

填写：

```text
旋律更好：A / B / 相同
```

### 3. 美学和target singer表现

- 是否自然。
- 电音、浴室感、含混或机械感是否变化。
- target singer和唱法是否更可信。
- 文本更完整后，整体是否真的更适合实际使用。

填写：

```text
美学更好：A / B / 相同
```

### 4. 综合选择

```text
综合选择：A / B / 都不可用
问题发生在第几句：
具体问题：
```

## 判定原则

- 文本提高但旋律明显恶化：不能直接通过。
- 自动 F0 提高但人耳觉得节奏或唱法更差：以人耳记录为独立事实，不用 F0 覆盖。
- 只改善第一句不算解决长音频问题。
- 后半段文本明显恢复，且旋律代价不可感或可接受，才支持将 T1 扩到完整 120 首。
- 即使 T1 胜出，美学仍不可用，也只说明句级锚点有效，不说明整个模型已可用。
