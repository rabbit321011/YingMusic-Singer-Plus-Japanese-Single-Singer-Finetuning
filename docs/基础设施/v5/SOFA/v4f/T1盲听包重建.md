# T1 盲听包重建

## 决策

- 20 条样本继续按总时长分层抽取。
- 全部 checkpoint 统一使用 T1 推理。
- T1 placement 使用整段 SOFA phrases，A/B 两侧都保留训练 tokens。
- 输入按 `ref_frames` 切成 A 参考区和 B 旋律区。
- `GT.wav` 与匿名模型 WAV 均只导出 B 区。
- 正式盲听包继续使用 `sample_xx/GT.wav + lyrics.txt + model_A...N.wav` 格式。

## 旧包失效原因

旧 `build_blind_package.py` 存在两个硬错误：

1. V4g/V4fg 虽使用 285k VAE 重新生成，但打包时旧 `EXISTING_BASE` 排在新产物前面，ZIP 实际优先复制了旧错误 WAV。
2. `run_audio_eval.py` 未按 manifest 的 `ref_frames` 切分 A/B，而是把完整原音频同时作为 reference 和 melody；之后又按 manifest 边界裁评测区，生成时间轴与评测时间轴不一致。

旧盲听包及旧 V4g/V4fg Audio Loss 不再作为有效证据。

## 新实现

脚本：

```text
${LOCAL_PROJECT_ROOT}\tools\audio_eval\build_blind_package_t1.py
```

关键行为：

- 显式维护 14 个 checkpoint → VAE 绑定表：V4c/V4f 使用官方 VAE，V4g/V4fg 使用 285k online VAE。
- 不读取或回退任何旧盲听 WAV；所有请求模型必须在新输出目录完整生成。
- 直接使用 SOFA manifest 中的训练 token，不重新 G2P。
- phrase 的 A/B 归属使用训练代码相同的 phrase-center 判定。
- A 区 phrase 保持原时间位置，并像训练一样在 `ref_len` 截断。
- B 区 phrase 相对 manifest 切点平移到实际 encoded reference 之后，包含通用 T1 推理的 0.5 秒参考尾静音。
- 保留 T1 的 token 重叠后移规则并记录 placement log。
- 生成后只解码并保存 B latent；输出样本数强制与 GT B 一致。
- 每个 WAV 保存 checkpoint、VAE、placement、SHA256: redacted
- 任一文件缺失或审计失败时整体报错，不生成残缺 ZIP。
- 日志实时打印全局进度、单样本耗时、累计运行时长与 ETA。

## 正式包修订

首个正式包人工检查发现部分 `GT.wav` 与 `lyrics.txt` 不完整对应。原因不是单一 ASR 结果：

- `lyrics.txt` 误展示整段 A+B phrases，而 WAV 只包含 B 区；
- 原 20 条中部分样本的 SOFA phrases 未覆盖完整 B 区，存在 4–9 秒未标注尾段；
- large-v3 仅作辅助诊断，音乐或空白段可能幻觉为「ご視聴ありがとうございました」，不作为歌词真值。

修订协议：

- 从 100 条 manifest 中筛选首个 B phrase 距切点 ≤0.25 秒、最后 phrase 距音频末尾 ≤0.25 秒、句间未标注间隔 ≤2 秒的样本；55 条通过。
- 在 55 条中重新按 B 时长分层选择 20 条。
- 先生成 GT+歌词预检包并由用户逐条确认。
- `lyrics.txt` 只展示 B 区 phrases。
- romaji 按 mora 分隔，如 `ko to shi no ... ki tto`。

- 全部为 `t1_full_phrases`，无 token 后移或溢出。
- 独立审计：20 样本、280 placements、320 ZIP 条目，全部 44.1kHz 双声道同帧，key 未入包。

当前候选锁定为 **V4fg 10k + 285k online VAE**。

跨模型共性观察：

- 第一句开头往往不是最佳状态，唱到中段开始改善，第二句后趋于稳定。
- target singer较少使用的轻柔音色上，整段 B 输出可能出现雾感。

第一句现象的优先嫌疑是推理 A→B 边界：当前通用 T1 在 A 参考后加入 0.5 秒静音，而训练 A/B 来自连续原音频、没有该静音。需用 V4fg 10k 固定输入比较 reference tail `0 / 0.25 / 0.5s`。

雾感需做 A/B 条件交换：固定 B 更换常见/罕见 A，固定 A 更换常见/轻柔 B，并分别检查 285k VAE 对 A/B 原音频的纯重建。雾感随 A 走说明参考条件/录音域主导；随 B 走说明旋律域或 DiT 对罕见唱法的均值化主导；若 VAE 重建已存在则先归因 VAE/源录音。
