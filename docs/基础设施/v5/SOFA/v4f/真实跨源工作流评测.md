# 真实跨源工作流评测

## 目的

用桌面 MIDI 工具构造真实跨源 A/B 输入，比较 V4fg、V4f、V4c、V4vf、V4Sf 24k/30k，以及 V4H 24k 在用户实际工作流中的表现。
这组评测补充此前 T1 正式盲听主要覆盖同源 A/B 与 B 原歌词分布的缺口。

每个评测组包含：

- A：参考音频及其 T1，提供音色与唱法条件；
- B：目标旋律音频及其 T1，提供待生成的旋律与歌词；
- 输出：模型生成的 B 区音频。

每个模型分别运行 CFG 3 和 CFG 1。其余条件固定为 Steps 32、Seed 42、CUDA、无 pitch shift。
十四个 checkpoint 批次各有 27 条输出，共 378 条基础模型结果；另有 27 条 A 区去混响工程实验，共 405 条 44.1kHz 单声道 WAV。全部可解码且非静音，与 B 输入最大时长偏差为 0.021406 秒。

V4Sf 24k/30k 原始训练 checkpoint 均含 3.395GiB optimizer state，直接加载会造成桌面端严重内存换页。评测使用从原文件提取并逐张量验真的 EMA-only 推理副本；模型权重内容未改变，原始训练 checkpoint 保留不动。

V4H 24k 使用独立 `phone_pul` 同构推理，不复用普通 T1 placement。27 组 A/B 均按训练时统一 kana、摩拉级 SOFA 输入、K=4 phone candidate 与正式 renderer 生成；最终 179 句中 141 句为 phone、38 句为 PUL、0 句为 exact Control，累计 2,659 个 PUL frame。CFG 3/1 的逐组 dense text 与 placement 审计完全一致。

## 工程方法：A 区 MSST 去混响

固定 V4fg 10k、285k online VAE、CFG 1、Steps 32、Seed 42，只将 27 条 A 区参考音频通过 MSST `dereverb_echo_mbr_fused_0.5_v2_0.25_big_0.25_super`，取 `dry` stem 后重新合成。

- MSST 输出原为 stereo，回填前按两声道均值转回 mono；
- 全部保持 44.1kHz，帧数与原 A 完全一致，T1 不变；
- 27/27 合成成功，全部可解码且非静音；
- 与 B 音频最大时长偏差 0.021406 秒；
- 27 条均与原 `V4fg_10k_cfg1` 不同，输出 RMS 差异范围约 0.0094–0.0551；
- 当前只确认方法确实改变生成结果，听感收益等待人工评分。
