# A7 与 MFA 实验

V5 P0 对齐线的早期实验记录。A7 是 Whisper large-v3 + fuzzy match 的粗句边界方案，
MFA 是局部强制对齐方案。本节记录两者的基线、问题画像和能力边界。

## A7 六分类评估

对 Gold Set（100 条、682 句）按正式分类口径评测：

| 类别 | 数量 | 定义 |
|---|---|---|
| 命中 | 201 | `gold_start - 1.0s <= pred_start <= gold_start + 0.5s` 且不后串 |
| 前串 | 233 | `pred_start < gold_start - 1.0s` |
| 前缩 | 131 | `pred_start > gold_start + 0.5s` |
| 后串 | 17 | `pred_end >= next_gold_start` |
| 整句错槽 | 0 | 非缺失且不属于以上 |
| 缺失 | 4 | 无对应匹配输出 |

抽象误差参考：MAE=1.882s，P95=6.62s。

## A7 统一扩窗实验

参数：句首前扩 `[0.0, 0.3, 0.5, 0.8]`，句尾后扩 `[0.0, 0.3, 0.5, 0.8]`。

结论：统一前扩可减少部分前缩，但显著增加前串。统一后扩显著增加后串。
**A7 不能靠简单统一扩窗修好。** 性价比差。

## MFA 基线

- 模型：`japanese_mfa`（acoustic + dictionary）
- 全局 MFA：P95=9.369s，MAE=3.946s。**很差，不可用。**
- 局部 MFA 链路可跑通（局部切句 → MFA → TextGrid），但能力边界实验未完成。

## 关键认知

- Gold Set 只用于评测真值，不能用于构造输入窗口。
- MFA 理想前提：音频咬字 = 参考文本。窗口混入额外咬字时能力受限。
- 当前分类口径由用户拍板，后续实验统一使用此口径。

## large-v3 基线实验

### raw large-v3 自然分段

不输入参考文本，直接取 faster-whisper large-v3 自然 segment。结果明显差于 A7：

| 类别 | 数量 |
|---|---|
| 命中 | 60 |
| 前串 | 101 |
| 前缩 | 165 |
| 后串 | 45 |
| 缺失 | 311 |

large-v3 自然分段平均 3.72 段/样本，Gold 平均 6.82 句/样本。segment 天然更粗，
经常一整段覆盖多句歌词。

### 分句粒度差异

100 条中，Gold 句数 > segment 数：68 条，等于：31 条，小于：1 条。
平均 Gold - segment = 3.1。large-v3 明显更粗。

### 覆盖 gold_start 偏差评测

按 segment 覆盖 gold_start 匹配后，偏差为：

| 类别 | 数量 |
|---|---|
| 命中 | 78 |
| 前串 | 366 |
| 前缩 | 0 |
| 后串 | 144 |
| 缺失 | 94 |

MAE = 1.915s，P95 = 6.263s。问题不是前缩，而是 segment 太宽（起点偏早 + 跨过下一句）。

### 首句粗窗口

以 large-v3 segment 为主，只取覆盖的第一个 Gold 句：命中 77，前串 206，后串 71。
MAE=1.172s，P95=2.632s。**可当粗窗口，不能当终边界。**

### large-v3 + MFA 细化

以 raw segment 为粗窗口，MFA 细化首句：

| 指标 | raw large-v3 | +MFA |
|---|---|---|
| 命中 | 77 | 177 |
| 前串 | 206 | 38 |
| 前缩 | 0 | 51 |
| 后串 | 71 | 83 |
| MAE | 1.172s | 0.856s |
| P95 | 2.632s | 2.562s |

MFA 能把大量起点偏早拉回来，但会引入一部分前缩，后串仍偏高。

### 二次 ASR 闭环

对 MFA 结果按 pred_start~pred_end 裁音频，重新用 large-v3 转录对比目标文本：

- ok_full：43/349（12.3%）
- ok_loose（sim>=0.8）：110/349（31.5%）
- 命中类 mean_sim=0.7069，前缩类 0.1367，后串类 0.4399

**大量区间文本不闭环。** 即使命中类，仍有大半起点看似不错但内容不是目标句。

### Gold100 直接反转录

直接使用 Gold Set 人工句区间裁音频，large-v3 反转录：

- ok_full：7/682，ok_loose：125/682，mean_sim=0.3351
- 整条样本严格通过：1/100，宽松通过：3/100

**即便给 large-v3 人工真区间，它也经常认不回目标句文本。** large-v3 不适合充当句级验证器。

## 总结

- raw large-v3 不适合直接做训练句边界，只适合做粗窗口
- large-v3 + MFA 改善句首位置，但区间内容仍不闭环
- large-v3 不充当句级验证器
- 该线最大价值是排除错误期待
