# 文档公开范围

本仓库尽量保留原创实验记录中的技术合同、诊断过程、失败案例和证据
边界。公开副本从私有工作区的文档生成，绝对路径、个人账号、私有链接、
文件指纹与连接信息经过脱敏。`tools/publish_research_docs.py` 是机械
脱敏入口；它不能代替提交前的人工审阅。

不随文档公开：训练音频、样本试听、缓存、模型权重、原始数据清单、
访问凭据和云盘下载地址。`temp_0529/official` 属于上游
源码副本，不作为原创文档重新发布；论文原文及整篇翻译也不在此次
文档同步范围内，读者应访问原作者的正式发布渠道。
私有资源总账、个人云盘操作记录、旧的代理对话归档也不进入此次同步。

部分研究计划记录了当时尚未执行的设计，其状态应以日期和所属分支
索引为准。脱敏占位符表示该位置原有私有路径或校验值，**不是**
可直接运行的下载地址。公开的 V5-PgO 和 V5PgOV 文档不包含可
复现私有数据集的全部输入。
